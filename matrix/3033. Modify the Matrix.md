# 3033. Modify the Matrix

## What I learned
* zip function returns an iterator of tuples  
* "*" unpacking / splat operator - passes each value as a seperate argument rather than the whole iterable.

## Approach
1. Use zip function to get the maxes for each column
2. When a negative number is found, replace the negative number with its respective column max
3. Return matrix when explored entirely

## Complexity
Time: O(m x n)
Aux Space: O(n)

## Solution
class Solution:
    def modifiedMatrix(self, matrix: List[List[int]]) -> List[List[int]]:

        column_max = [max(column) for column in zip(*matrix)]
        
        for i, row in enumerate(matrix):
            for j, num in enumerate(row):
                if num < 0:
                    matrix[i][j] = column_max[j]
        
        return matrix
