# 1978. Employees Whose Manager Left the Company
## What I learned
* Subqueries in WHERE clause — IN/NOT IN checks membership against another query's result
* NOT IN can behave unexpectedly with NULLs — always add IS NOT NULL guard when using NOT IN
* ORDER BY without explicit clause gives no guaranteed ordering in SQL
## Approach
1. Filter employees with salary < 30000
2. Filter employees who have a manager (manager_id IS NOT NULL)
3. Filter employees whose manager_id doesn't exist in the employee_id column (manager left)
4. Order by employee_id
## Solution
```sql
SELECT employee_id 
FROM Employees 
WHERE salary < 30000
AND manager_id IS NOT NULL
AND manager_id NOT IN (SELECT employee_id FROM Employees)
ORDER BY employee_id;
```
