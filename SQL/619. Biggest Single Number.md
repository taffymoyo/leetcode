# 619. Biggest Single Number
## What I learned
* HAVING filters groups after GROUP BY — here filtering for groups with count = 1 gives single numbers
* Wrapping a query as a subquery lets you apply aggregate functions like MAX on the filtered result
* MAX on an empty set returns NULL automatically — no need to handle the "no single number" case explicitly
## Approach
1. Subquery: group by num, filter with HAVING count(*) = 1 to get single numbers only
2. Outer query: take MAX of those single numbers — returns NULL if subquery is empty
## Solution
```sql
SELECT MAX(num) AS num 
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
) AS singles;
```
