# 175. Combine Two Tables
## What I learned
* LEFT JOIN keeps all rows from the left table, filling NULL for unmatched right table columns
* RIGHT JOIN is the mirror — keeps all rows from the right table
* INNER JOIN only keeps rows with matches in both tables
* Dot notation (Table.column) disambiguates columns that exist in both tables
* In relational algebra: ⟕ is left outer join, ⋈ is inner join
## Approach
1. LEFT JOIN Person with Address on matching personId
2. This keeps all persons even if they have no address (city and state become NULL)
3. Select the four required columns
## Solution
```sql
SELECT firstName, lastName, city, state 
FROM Person
LEFT JOIN Address ON Person.personId = Address.personId;
```
