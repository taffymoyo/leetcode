# 182. Duplicate Emails
## What I learned
* HAVING COUNT(*) > 1 filters for groups with more than one row — perfect for finding duplicates
* Subquery approach: find duplicates in inner query, select just the email in outer query
* Could also do it without subquery: SELECT email FROM Person GROUP BY email HAVING COUNT(*) > 1
## Approach
1. Group by email
2. Filter groups with count > 1 using HAVING
3. Select the email column
## Solution
```sql
SELECT email 
FROM (
    SELECT email 
    FROM Person
    GROUP BY email
    HAVING COUNT(*) > 1
) AS dups;
```
