# 2335. Minimum Amount of Time to Fill Cups
## What I learned
* Each second, fill one cup from each of the two types with the most cups remaining. That's a "take the two largest, change them, put them back" pattern, which is what a heap is for
* heapq is a min-heap, so negate the values to simulate a max-heap. The smallest negative is the largest pile
* A heap doesn't re-adjust if you edit an element in place. Pop it, change it, and push it back
* heappop and heappush return nothing useful on push (heappush returns None), so don't assign its result
* Zeros are normal elements in a heap, so filter finished piles out yourself (only push back if a pile still has cups)
* Sorting once isn't enough because the order changes every second. Re-sorting each time works but costs O(k log k) per step, while the heap only repairs what changed in O(log k)
## Approach
### Heap
1. Put the non-empty piles on a max-heap (negated values)
2. While at least two piles remain, pop the two largest and fill one cup from each, which takes one second
3. Push each pile back if it still has cups left
4. If one pile is left, it takes one second per cup, so add its size
### Shortcut
1. The answer is at least the biggest pile, since each pile loses at most one cup per second
2. The answer is at least ceil(total / 2), since at most 2 cups are filled per second
3. The answer is the larger of those two bounds
## Complexity
Heap: Time O(T log k) where T is the number of seconds and k is the number of cup types (k = 3 here), Aux Space O(k)
Shortcut: Time O(1), Aux Space O(1)
## Heap Solution
```python
import heapq

class Solution:
    def fillCups(self, amount: list[int]) -> int:
        
        heap = [-x for x in amount if x > 0]
        heapq.heapify(heap)
        count = 0

        while len(heap) >= 2:
            a = heapq.heappop(heap)
            b = heapq.heappop(heap)

            a, b = a + 1, b + 1

            if a < 0:
                heapq.heappush(heap, a)
            if b < 0:
                heapq.heappush(heap, b)
            
            count += 1
            
        if heap:
            return count - heap[0]
        return count
```
## Shortcut Solution
```python
class Solution:
    def fillCups(self, amount: list[int]) -> int:
        return max(max(amount), (sum(amount) + 1) // 2)
```
