# 2437. Number of Valid Clock Times
## What I learned
* Brute force all valid times is cleaner than case analysis — only 24*60=1440 possibilities
* String comparison works for digit characters since '4' > '3' etc.
* Hour and minute unknowns are independent — multiply valid hours by valid minutes
## Approach
1. Handle hour digits separately based on constraints (hh must be 00-23)
2. Handle minute digits separately (mm must be 00-59)
3. Multiply valid hours by valid minutes
## Complexity
Time: O(1) — fixed number of cases  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countTime(self, time: str) -> int:
        
        hours = 0
        for i in range(2):
            if time[i] == "?":
                if i == 0:
                    if time[i + 1] != "?" and time[i + 1] >= "4":
                        hours += 2
                    elif time[i + 1] != "?" and time[i + 1] < "4":
                        hours += 3
                    else:
                        hours += 24
                        break
                elif i == 1:
                    if time[i - 1] != "?" and time[i - 1] == "2":
                        hours += 4
                    elif time[i - 1] != "?" and time[i - 1] < "2":
                        hours += 10
        mins = 0
        for i in range(3, 5):
            if time[i] == "?":
                if i == 3:
                    mins += 6
                if i == 4:
                    if time[i - 1] != "?":
                        mins += 10
                    else: 
                        mins = 60
        
        if mins == 0 and hours == 0:
            return 1
        if hours == 0:
            return mins
        if mins == 0:
            return hours
        return hours * mins
```
