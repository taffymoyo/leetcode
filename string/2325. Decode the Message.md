# 2325. Decode the Message
## What I learned
* .join doesn't strip anything, it only concatenates with the separator between elements. An empty separator just means nothing is inserted
* A set tracks which characters have already been seen, so the key keeps only the first occurrence of each letter in order
* list.index(char) finds a character's position in the cipher key, which maps straight to the same position in the alphabet
## Approach
1. Build the cipher key by taking the first occurrence of each letter in key, skipping spaces and repeats
2. The i-th letter in the cipher key maps to the i-th letter of the alphabet
3. For each character in message, look up its position in the cipher key and take the alphabet letter at that position, keeping spaces as they are
## Complexity
Time: O(n + m) where n is len(key) and m is len(message). index() scans at most 26 elements so it is effectively O(1)  
Aux Space: O(1), since the key and alphabet are capped at 26 letters
## Solution
```python
class Solution:
    def decodeMessage(self, key: str, message: str) -> str:

        alphabet = list("abcdefghijklmnopqrstuvwxyz")

        seen = set()
        new_key = []
        for char in key:
            if char != " " and char not in seen:
                seen.add(char)
                new_key.append(char)

        result = []
        for char in message:
            if char != " ":
                result.append(alphabet[new_key.index(char)])
            else:
                result.append(" ")
        
        return "".join(result)
```
