2942. Find Words Containing Character

## What I learned
* nothing easy question

## Approach
1. Find if the target letter is in the word and append it to the result
2. Return indices with the target letter in a result list

## Complexity
Time: O(n)  
Aux Space: O(n)

## Solution
class Solution:
    def findWordsContaining(self, words: List[str], x: str) -> List[int]:

        result = []

        for i, word in enumerate(words):
            if x in word:
                result.append(i)
        
        return result
