# 2520. Count the Digits That Divide a Number
## What I learned
* Two ways to extract digits: string conversion O(d) space, or repeated division O(1) space
* When using repeated division, save the original number since you need it for the divisibility check
## Approach
### String Approach
1. Convert num to string to iterate over digits
2. For each digit check if it divides num evenly
### Division Approach
1. Save original num, extract digits via repeated % 10 and // 10
2. Check each digit against the original num
3. O(1) space since no string allocation needed
## Complexity
Time: O(d) where d is the number of digits
String Approach Aux Space: O(d)
Division Approach Aux Space: O(1)
## String Solution
```python
class Solution:
    def countDigits(self, num: int) -> int:

        digits = 0
        str_num = str(num)

        for digit in str_num:
            if num % int(digit) == 0:
                digits += 1
        
        return digits
```
## Division Solution
```python
class Solution:
    def countDigits(self, num: int) -> int:

        digits = 0
        org = num

        while org > 0:
            remainder = org % 10
            org //= 10
            if num % remainder == 0:
                digits += 1

        return digits
```
