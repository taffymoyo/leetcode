# 2520. Count the Digits That Divide a Number
## What I learned
* Nothing new, comfortable with digit extraction via string conversion
## Approach
1. Convert num to string to iterate over digits
2. For each digit, check if it divides num evenly
3. Return the count
## Complexity
Time: O(d) where d is the number of digits  
Aux Space: O(d) for the string conversion
## Solution
```python
class Solution:
    def countDigits(self, num: int) -> int:

        digits = 0
        str_num = str(num)

        for digit in str_num:
            if num % int(digit) == 0:
                digits += 1
        
        return digits
```
