# 3019. Number of Changing Keys
## What I learned
* .lower() on both chars handles the shift/caps lock case cleanly
## Approach
1. Iterate through the string comparing each character to the previous one
2. Lowercase both before comparing to ignore shift/caps lock
3. Increment count when they differ
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countKeyChanges(self, s: str) -> int:
        
        count = 0
        for i, char in enumerate(s):
            if i > 0:
                if char.lower() != s[i-1].lower():
                    count += 1
        
        return count
```
