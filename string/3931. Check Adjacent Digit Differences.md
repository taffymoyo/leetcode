# 3931. Check Adjacent Digit Differences
## What I learned
* Nothing new, comfortable with adjacent element comparison pattern
## Approach
1. Iterate through adjacent pairs of digits
2. Return False if absolute difference exceeds 2
3. Otherwise return True
## Complexity
Time: O(n)
Aux Space: O(1)
## Solution
```python
class Solution:
    def isAdjacentDiffAtMostTwo(self, s: str) -> bool:
        
        for i, num in enumerate(s):
            if i < len(s) - 1:
                if abs(int(num) - int(s[i + 1])) > 2:
                    return False
            
        return True
```
