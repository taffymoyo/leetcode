# 3884. First Matching Character From Both Ends
## What I learned
* Early return removes the need to track a minimum — first match found is always smallest
* Only need to check up to n//2 since pairs mirror after that
## Approach
1. Iterate from both ends simultaneously
2. Return immediately on first match — guaranteed to be smallest index
3. Return -1 if no match found
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def firstMatchingIndex(self, s: str) -> int:
        
        n = len(s)

        for i in range(n // 2 + 1):
            if s[i] == s[n - i - 1]:
                return i
        
        return -1
```
