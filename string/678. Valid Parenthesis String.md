# 678. Valid Parenthesis String
## What I learned
* Store indices not just characters — position matters when matching * with unmatched (
* * must appear AFTER the ( it closes, so index of * must be greater than index of (
* Stars can be left over at the end (they can represent empty string) but unmatched ( cannot
* Was very close to solving this medium independently — core logic was right, just needed index tracking
* I almost solved this one entirely on my own, just couldn't figure out that I had to store the indices too, oh well i did 90% of the work
## Approach
1. Use two stacks — one for ( indices, one for * indices
2. On ), use ( first, then * to close — if neither available return False
3. After processing, match remaining ( with * — * index must be greater than ( index
4. If any ( has no valid * to match, return False
## Complexity
Time: O(n)
Aux Space: O(n) for the two stacks
## Solution
```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        
        stack = []
        stars = []

        for i, char in enumerate(s):
            if char == "(":
                stack.append(i)
            elif char == "*":
                stars.append(i)
            else:
                if stack:
                    stack.pop()
                    continue
                if stars:
                    stars.pop()
                    continue
                return False
        
        while stack:
            if stars:
                if stars[-1] <= stack[-1]:
                    return False
                stack.pop()
                stars.pop()
            else:
                return False
        
        return True
```
