# 551. Student Attendance Record I
## What I learned
* Reset late counter on P or A — only consecutive L's count
* Track absent count separately — can be non-consecutive
## Approach
1. Track consecutive late count and total absent count
2. Reset late on P or A
3. Increment late on L, return False if 3 consecutive
4. Return False if 2 or more absences
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def checkRecord(self, s: str) -> bool:

        late, absent = 0, 0

        for char in s:
            if char == "P":
                late = 0
                
            if char == "A":
                absent += 1
                late = 0

            elif char == "L":
                late += 1
                if late == 3:
                    return False
        
        return absent < 2
```
