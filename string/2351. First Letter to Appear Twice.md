# 2351. First Letter to Appear Twice
## What I learned
* Nothing new, just confident set usage
## Approach
1. Iterate through the string tracking seen characters in a set
2. Return immediately when a character is seen for the second time
## Complexity
Time: O(n)  
Aux Space: O(1) — at most 26 lowercase letters in the set
## Solution
class Solution:
    def repeatedCharacter(self, s: str) -> str:

        seen = set()
        for char in s:
            if char in seen:
                return char
            seen.add(char)
