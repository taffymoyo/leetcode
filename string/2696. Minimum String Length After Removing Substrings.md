# 2696. Minimum String Length After Removing Substrings
## What I learned
* Stack is the natural fit for "remove adjacent pairs" problems — same pattern as Make The String Great
* Deleting from a list while iterating and resetting is O(n²); stack approach is O(n)
## Approach
### Brute Force O(n²)
1. Convert string to list
2. Scan for "AB" or "CD" pairs, delete them, reset to start
3. Repeat until no more pairs found
### Optimal O(n) — Stack
1. For each character, check if it forms a removable pair with the top of the stack
2. If so, pop the stack; otherwise push the character
3. Return the length of the remaining stack
## Complexity
Brute Force — Time: O(n²), Aux Space: O(n)
Optimal — Time: O(n), Aux Space: O(n)
## Brute Force Solution
```python
class Solution:
    def minLength(self, s: str) -> int:
        temp = list(s)

        i, j = 0, 2
        while i < len(temp):
            if temp[i:j] == ['A', 'B'] or temp[i:j] == ['C', 'D']:
                del temp[i:j]
                i, j = 0, 2
            else:
                i, j = i + 1, j + 1
            
        return len(temp)
```
## Optimised Solution — Stack
```python
class Solution:
    def minLength(self, s: str) -> int:
        stack = []
        for c in s:
            if not stack:
                stack.append(c)
                continue
            if c == "B" and stack[-1] == "A":
                stack.pop()
            elif c == "D" and stack[-1] == "C":
                stack.pop()
            else:
                stack.append(c)
        return len(stack)
```
