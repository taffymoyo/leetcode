# 1507. Reformat Date
## What I learned
* Split on spaces to get day, month, year as separate tokens
* Dict maps month abbreviations to zero-padded numbers
* Day needs zero-padding for single digit days — strip suffix with slice
## Approach
1. Split date into components
2. Map month to number using dict
3. Handle day padding — 2-digit days take first 2 chars, 1-digit days prepend "0"
4. Join in YYYY-MM-DD format
## Complexity
Time: O(1) — fixed length string  
Aux Space: O(1)
## Solution
```python
class Solution:
    def reformatDate(self, date: str) -> str:
        
        months = {"Jan": "01","Feb": "02","Mar": "03","Apr": "04","May": "05","Jun": "06","Jul": "07","Aug": "08","Sep": "09","Oct": "10","Nov": "11","Dec": "12"}

        result = []
        date = date.split()

        result.extend([date[2], "-"])
        result.extend([months[date[1]], "-"])

        day = date[0]
        if len(day) == 4:
            result.append(day[:2])
        else:
            result.extend(["0", day[0]])
        
        return "".join(result)
```
