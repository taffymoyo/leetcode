# 3168. Minimum Number of Chairs in a Waiting Room
## What I learned
* Minimum chairs = peak concurrent occupancy — chairs stay in the room, they just become available when someone leaves
* Stack overkill here — a simple counter tracking current occupancy and its max is sufficient
## Approach
1. Track current number of people in the room
2. Increment on E, decrement on L
3. Return the peak value seen
## Complexity
Time: O(n)  
Aux Space: O(1) with counter, O(n) with stack
## Solution
```python
class Solution:
    def minimumChairs(self, s: str) -> int:

        stack = []
        max_length = 0

        for char in s:
            if char == "E":
                stack.append(1)
            else:
                stack.pop()

            if len(stack) > max_length:
                max_length = len(stack)

        return max_length
```
