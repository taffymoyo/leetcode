# 1614. Maximum Nesting Depth of the Parentheses
## What I learned
* Track depth with a running counter, increment on '(' and decrement on ')'
* Max depth is just the peak value of the counter
## Approach
1. Iterate through the string tracking current depth
2. Increment on '(', decrement on ')'
3. Track the maximum depth seen at any point
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def maxDepth(self, s: str) -> int:

        count = 0
        max_count = 0
        for char in s:
            if char == "(":
                count += 1
            elif char == ")":
                count -= 1

            if count > max_count:
                max_count = count
        
        return max_count
```
