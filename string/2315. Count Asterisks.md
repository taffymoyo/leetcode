# 2315. Count Asterisks
## What I learned
* Stack used as a toggle — push on first |, pop on second | to track whether inside a pipe pair
* Only count * when stack is empty (outside pipe pairs)
## Approach
1. Push | onto stack when outside a pair, pop when inside (closing the pair)
2. Count * only when stack is empty
## Complexity
Time: O(n)  
Aux Space: O(1) — stack holds at most one element
## Solution
```python
class Solution:
    def countAsterisks(self, s: str) -> int:
        
        stack = []
        count = 0

        for char in s:
            if char == "|" and not stack:
                stack.append(char)
            elif char == "|" and stack:
                stack.pop()
            elif char == "*":
                if not stack:
                    count += 1
        
        return count
```
