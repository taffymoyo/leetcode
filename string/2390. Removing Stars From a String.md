# 2390. Removing Stars From a String
## What I learned
* Stack is the natural fit for "remove previous element" problems
* Append non-star characters, pop on star — clean and O(n)
* Just found out you can run test cases on leetcode without submitting LOL, my acceptance rate is cooked time to fix taht
## Approach
1. Use a list as a stack
2. Append each non-star character
3. Pop the top when a star is encountered
4. Join and return
## Complexity
Time: O(n)  
Aux Space: O(n) for the stack
## Solution
```python
class Solution:
    def removeStars(self, s: str) -> str:

        result = []
        for i, char in enumerate(s):
            if char == "*":
                result.pop()
            else:
                result.append(char)

        return "".join(result)
```
