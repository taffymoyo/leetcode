# 1869. Longer Contiguous Segments of Ones than Zeros
## What I learned
* Track a current streak and a max streak for each digit, and reset the other digit's current streak whenever the character changes
* If a digit never appears, its max stays at 0, which matches the problem's rule for missing 0s or 1s
* The comparison is strict (>), so a tie returns False
## Approach
1. Walk through the string keeping the current run length of 1s and 0s
2. On a 1, increment one_count and reset zero_count (and the reverse for a 0)
3. Update the max for that digit after each increment
4. Return whether the longest run of 1s is strictly greater than the longest run of 0s
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def checkZeroOnes(self, s: str) -> bool:

        one_count, zero_count, max_zeros, max_ones = 0, 0, 0, 0

        for char in s:
            if char == "1":
                zero_count = 0
                one_count += 1
                if one_count > max_ones:
                    max_ones = one_count
            elif char == "0":
                one_count = 0
                zero_count += 1
                if zero_count > max_zeros:
                    max_zeros = zero_count
        
        return max_ones > max_zeros
```
