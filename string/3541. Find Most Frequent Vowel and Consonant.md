# 3541. Find Most Frequent Vowel and Consonant
## What I learned
* Nothing new, comfortable with Counter and character classification
## Approach
1. Count frequency of each character using Counter
2. Track the max frequency seen for vowels and consonants separately
3. Return the sum of the two maximums
## Complexity
Time: O(n)  
Aux Space: O(1) — at most 26 keys in Counter
## Solution
```python
class Solution:
    def maxFreqSum(self, s: str) -> int:

        vowels = "aeiou"
        v, c = 0, 0
        counts = Counter(s)

        for k, val in counts.items():
            if k in vowels:
                if val > v:
                    v = val
            else:
                if val > c:
                    c = val
        
        return v + c
```
