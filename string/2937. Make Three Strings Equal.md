# 2937. Make Three Strings Equal.md

## What I learned
* Improved my prefix matching skills

## Approach
1. Find the minimum length string because all strings will be bottlenecked by the minimum length string regardless.
2. Find the longest common prefix amongst the 3 strings.
3. Trim the remainder characters and add them to the count to be returned at the end.

## Complexity
Time: O(n) where n is the length of the shortest string
Aux Space: O(1)

## Solution
class Solution:
    def findMinimumOperations(self, s1: str, s2: str, s3: str) -> int:
        
        shortest = min(len(s1), len(s2), len(s3))
        count = 0
        longest_prefix = 0

        for i in range(shortest):
            if s1[i] == s2[i] == s3[i]:
                longest_prefix += 1
            else:
                break
        
        count += len(s1) - longest_prefix
        count += len(s2) - longest_prefix
        count += len(s3) - longest_prefix

        return count if longest_prefix != 0 else -1
