# 2451. Odd String Difference

## What I learned
* Difference arrays are a clean way to compare relative character patterns  
* Bucket approach: split into two groups and return whichever has only one element

## Approach
1. Compute the difference array of the first word as the reference
2. Bucket all words into arr1 (matches reference) or arr2 (doesn't match)
3. The odd one out is whichever bucket has only one element

## Complexity

Time: O(n * m) where n is the number of words and m is the length of each word  
Aux Space: O(n) for the two buckets

## Solution
class Solution:
    def oddString(self, words: List[str]) -> str:

        arr1, arr2 = [], []

        def diff(word):
            return [ord(word[j+1]) - ord(word[j]) for j in range(len(word)-1)]

        first_diff = diff(words[0])

        for word in words:
            if diff(word) == first_diff:
                arr1.append(word)
            else:
                arr2.append(word)

        return arr2[0] if len(arr2) == 1 else arr1[0]
