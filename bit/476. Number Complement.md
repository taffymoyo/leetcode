# 476. Number Complement
## What I learned
* bin(num) includes "0b" prefix — always slice with [2:] or start loop at index 2
* Indexing into the original string while iterating a range over the sliced length causes an off-by-two bug
## Approach
1. Convert num to binary string, strip the "0b" prefix
2. Flip each bit: "1" → "0", "0" → "1"
3. Convert result back to int with base 2
## Complexity
Time: O(d) where d is the number of bits
Aux Space: O(d) for the result list
## Solution
```python
class Solution:
    def findComplement(self, num: int) -> int:
        bin_num = bin(num)
        
        list_bin_num = list(bin_num)
        for i in range(2, len(list_bin_num)):
            if list_bin_num[i] == "1":
                list_bin_num[i] = "0"
            else:
                list_bin_num[i] = "1"
            
        list_bin_num = list_bin_num[2:]
        return int("".join(list_bin_num), 2)
```
