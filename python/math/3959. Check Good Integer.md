# 3959. Check Good Integer
## What I learned
* Digit extraction is `n % 10` for the last digit and `n //= 10` to drop it, and this is the base-10 case of the repeated division pattern
* Several digit-based stats (sum, sum of squares) can be accumulated in a single pass, so there's no need to store the digits or convert to a string
## Approach
1. Repeatedly extract the last digit, adding it to a running digit sum and its square to a running square sum
2. Return whether `square_sum - digit_sum >= 50`
## Complexity
Time: O(log₁₀(n)), the number of digits in n    
Aux Space: O(1)
## Solution
```python
class Solution:
    def checkGoodInteger(self, n: int) -> bool:

        digit_sum, square_sum = 0, 0

        while n > 0:
            digit = n % 10
            digit_sum += digit
            square_sum += digit**2
            n //= 10

        return square_sum - digit_sum >= 50
```
