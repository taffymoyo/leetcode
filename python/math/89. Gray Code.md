# 89. Gray Code
## What I learned
* Gray code formula: gray(i) = i ^ (i >> 1)
* >> is right shift — equivalent to floor dividing by 2, drops the rightmost bit
* XORing i with i>>1 produces a sequence where adjacent numbers always differ by exactly one bit
* This is one of those formulas you either know or look up — hard to derive from scratch
## Approach
1. For each i from 0 to 2^n - 1, compute i ^ (i >> 1)
2. This directly gives the gray code sequence
## Complexity
Time: O(2^n)  
Aux Space: O(2^n) for the result
## Solution
```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        return [i ^ (i >> 1) for i in range(2**n)]
```
