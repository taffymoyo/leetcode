# 3794. Reverse String Prefix

## What I learned
* More confidence in two pointers

## Approach
1. Have a pointer i at index 0, and j at index k - 1
2. Swap elements at arr i and j with each other and increment and decrement both pointers respectively with the termination condition being while j > i
3. Return the resulting array back as a string.

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
class Solution:
    def reversePrefix(self, s: str, k: int) -> str:
        arr = list(s)

        i, j = 0, k - 1
        while j > i:
            arr[i], arr[j] = arr[j], arr[i]
            i, j = i + 1, j - 1
        
        return "".join(arr)
