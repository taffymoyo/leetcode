# 2697. Lexicographically Smallest Palindrome

## What I learned
* Two pointers can compare characters from opposite ends of a string
* A palindrome requires mirrored characters to be identical
* Replacing the larger character with the smaller one guarantees the lexicographically smallest palindrome with minimum operations
* Convert strings to lists because strings are immutable in Python
* `"".join()` converts the modified character list back into a string

## Approach
1. Initialise left and right pointers at opposite ends of the string
2. Convert the string into a list so characters can be modified
3. While `l < r`, compare the characters at both pointers
4. If they differ, replace the larger character with the smaller one
5. Move both pointers towards the centre
6. Join the list and return the palindrome

## Complexity
Time: O(n) — each character is visited once  
Aux Space: O(n) — character list stores a copy of the string

## Solution
```python
class Solution:
    def makeSmallestPalindrome(self, s: str) -> str:

        l, r, result = 0, len(s) - 1, list(s)

        while l < r: 
            if result[l] != result[r]:
                if result[r] < result[l]:
                    result[l] = result[r]
                else:
                    result[r] = result[l]
            l += 1
            r -= 1
        
        return "".join(result)
```
