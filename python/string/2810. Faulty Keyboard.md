# 2810. Faulty Keyboard
## What I learned
* Sometimes the straightforward simulation is the right approach
## Approach
1. Iterate through each character
2. Append non-'i' characters to result
3. Reverse result whenever 'i' is encountered
## Complexity
Time: O(n²) in worst case — each reverse is O(n) and could happen n times  
Aux Space: O(n)
## Solution
class Solution:
    def finalString(self, s: str) -> str:
        arr = list(s)
        result = []

        for char in arr:
            if char != "i":
                result.append(char)
            else:
                result.reverse()
        
        return "".join(result)
