## Approach
1. Use an i loose i variable (for loop with skip = 2 works too but I preferred this)
2. Because the string is guaranteed to be 2n length every time, it is confirmed that every ring will come in the form [colour, ring_number]
3. Have a rings list that tracks each ring and which colours are present on each ring
4. Count the rings in the ring list at the end, if a ring has at least one of every colour add it to the final count
5. Return the count

## Complexity
Time: O(n)
Aux Space: O(1)

## Solution
class Solution:
    def countPoints(self, rings: str) -> int:

        ring_positions = [[0,0,0] for i in range(10)]

        count = 0
        i = 0

        while i < len(rings) - 1:
            ring_index = int(rings[i+1])
      
            if rings[i] == "R":
                ring_positions[ring_index][0] += 1
            if rings[i] == "G":
                ring_positions[ring_index][1] += 1
            if rings[i] == "B":
                ring_positions[ring_index][2] += 1
            
            i += 2
        
        for ring in ring_positions:
            if all(x >= 1 for x in ring):
                count += 1
        
        return count
