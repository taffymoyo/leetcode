# 2278. Percentage of Letter in String
## What I learned
* int() truncates toward zero — correct for "rounded down" requirement
* count / len * 100 gives percentage, int() floors it
## Approach
1. Count occurrences of letter
2. Divide by string length, multiply by 100, truncate with int()
## Complexity
Time: O(n)   
Aux Space: O(1)
## Solution
```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:

        count = 0
        for char in s:
            if char == letter:
                count += 1
        return int(count / len(s) * 100)
```
