# 3498. Reverse Degree of a String
## What I learned
* ord('z') - ord(char) + 1 cleanly gives the reversed alphabet position
* enumerate(s, start=1) for 1-indexed positions without manual i tracking
## Approach
1. For each character, compute its reversed alphabet value: ord('z') - ord(char) + 1
2. Multiply by its 1-indexed position in the string
3. Sum all products
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def reverseDegree(self, s: str) -> int:

        total = 0
        for i, char in enumerate(s, start=1):
            reverse_degree = ord('z') - ord(char) + 1
            total += reverse_degree * i
        
        return total
```
