# 2409. Count Days Spent Together
## What I learned
* Day of year formula: sum(months[:mo-1]) + day — sum months BEFORE current month (mo-1 not mo)
* Overlap of two inclusive ranges [a,b] and [c,d]: max(0, min(b,d) - max(a,c) + 1)
* Extract month with date[:2], day with date[3:] from "MM-DD" format
## Approach
1. Convert all four dates to day-of-year integers
2. Overlap starts at max of arrival dates, ends at min of departure dates
3. Return max(0, overlap_end - overlap_start + 1)
## Complexity
Time: O(1)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:

        months = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        def doy(date):
            mo, day = int(date[:2]), int(date[3:])
            return sum(months[:mo-1]) + day

        a_arr = doy(arriveAlice)
        a_leave = doy(leaveAlice)
        b_arr = doy(arriveBob)
        b_leave = doy(leaveBob)

        return max(0, min(a_leave, b_leave) - max(a_arr, b_arr) + 1)
```
