# 4006. Count Valid Prefixes
## What I learned
* Recomputing counts from scratch each iteration is O(n²) — maintaining running counts is O(n)
* Same prefix sum mindset: update incrementally rather than recompute
## Approach
### Brute Force O(n²)
1. For each prefix length i, count 0s and 1s in the prefix from scratch
2. Check if absolute difference < 2
3. Increment count if valid
### Optimised O(n)
1. Maintain running counts of 0s and 1s as you scan left to right
2. Check condition after each character — no recomputation needed
## Complexity
Brute Force — Time: O(n²), Aux Space: O(n) for slices
Optimised — Time: O(n), Aux Space: O(1)
## Brute Force Solution
```python
class Solution:
    def countValidPrefixes(self, s: str) -> int:

        count = 0
        i = 0
        while i <= len(s):
            zero_count, one_count = 0, 0
            for char in s[:i]:
                zero_count = s[:i].count("0")
                one_count = s[:i].count("1")

            if abs(zero_count - one_count) < 2:
                count += 1
    
            i += 1
        
        return count - 1
```
## Optimised Solution
```python
class Solution:
    def countValidPrefixes(self, s: str) -> int:

        count = 0
        zero, one = 0, 0 

        i = 0
        while i < len(s):
            if s[i] == "0":
                zero += 1
            else:
                one += 1
            
            if abs(zero - one) < 2:
                count += 1
            
            i += 1
        
        return count
```
