# 1790. Check if One String Swap Can Make Strings Equal
## What I learned
* At most one swap means exactly 0 or 2 mismatches — and the two mismatched pairs must be each other's swap
* Storing mismatch indices and cross-checking is cleaner than trying all swaps
## Approach
### Brute Force O(n²)
1. Try every pair of swap positions in s2
2. Return True if any swap makes s2 equal to s1
### Optimal O(n)
1. Find all mismatch indices
2. Must have exactly 2 mismatches
3. Check if swapping those two positions in s2 would fix both
## Complexity
Brute Force — Time: O(n²), Aux Space: O(n)  
Optimal — Time: O(n), Aux Space: O(1) — at most 2 indices stored
## Brute Force Solution
```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        
        list_s1 = list(s1)
        list_s2 = list(s2)

        if list_s1 == list_s2:
            return True

        for i in range(len(list_s2) - 1):
            for j in range(i + 1, len(list_s2)):
                list_s2[i], list_s2[j] = list_s2[j], list_s2[i]
                if list_s1 == list_s2:
                    return True
                list_s2[i], list_s2[j] = list_s2[j], list_s2[i]

        return False
```
## Optimised Solution
```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        if s1 == s2:
            return True
        
        diff = []
        for i in range(len(s1)):
            if s1[i] != s2[i]:
                diff.append(i)
                
        return len(diff) == 2 and s1[diff[0]] == s2[diff[1]] and s1[diff[1]] == s2[diff[0]]
```
