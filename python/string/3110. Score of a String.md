# 3110. Score of a String
## What I learned
* Nothing new, comfortable with ord() and adjacent element iteration
## Approach
1. Iterate through adjacent character pairs
2. Sum the absolute difference of their ASCII values
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def scoreOfString(self, s: str) -> int:

        count = 0
        for i in range(len(s)):
            if i < len(s) - 1:
                count += abs(ord(s[i]) - ord(s[i + 1]))
        
        return count
```
