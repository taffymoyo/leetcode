# 1624. Largest Substring Between Two Equal Characters

## What I learned
* `enumerate()` provides both the index and character when iterating through a string.
* Nested loops can be used to find matching characters at different indices.
* Characters between two indices can be calculated using `j - i - 1`.
* Initialising maximum to `-1` handles cases where no matching characters exist.
* `max()` keeps track of the largest substring length found.

## Approach
1. Initialise `maximum = -1` to handle strings with no matching characters.
2. Iterate through the string using `enumerate()` to get each character and its index.
3. Use a nested loop to search backwards from the end of the string.
4. If the characters match, calculate the substring length using `j - i - 1`.
5. Update maximum if a larger substring is found.
6. Return maximum.

## Complexity
Time: O(n²) — nested loops iterate through the string.

Aux Space: O(1) — only a constant amount of additional space is used.

## Solution
```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:

        maximum = -1

        for i, char in enumerate(s):
            for j in range(len(s) - 1, i, -1):
                if char == s[j]:
                    maximum = max(j - i - 1, maximum)
        
        return maximum
```
