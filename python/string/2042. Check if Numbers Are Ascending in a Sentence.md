# 2042. Check if Numbers Are Ascending in a Sentence
## What I learned
* str.isdigit() checks if a string consists entirely of digits — useful for filtering words vs numbers after split()
* Initialising digit at -1 is safe since sentence numbers are positive
## Approach
1. Split sentence into words
2. For each word that is a number, check it's greater than the previous number seen
3. Return False if any number is not strictly greater, True otherwise
## Complexity
Time: O(n) where n is the length of the string  
Aux Space: O(n) for the split
## Solution
```python
class Solution:
    def areNumbersAscending(self, s: str) -> bool:

        digit = -1
        for word in s.split():
            if word.isdigit():
                if int(word) > digit:
                    digit = int(word)
                else:
                    return False
        return True
```
