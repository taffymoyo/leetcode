# 394. Decode String
## What I learned
* Stack handles nested structures naturally — each ] only cares about its own layer
* Push decoded strings back onto the stack so outer brackets can access inner results
* Multi-digit numbers pushed as individual chars — need while loop with stack and stack[-1].isnumeric() guard
* The outer ] collects everything including previously decoded inner strings and repeats them all together
## Approach
1. Push all characters onto stack
2. On ], pop until [ to get inner string, pop [ then pop digits for count
3. Multiply inner string by count and push back onto stack
4. At end join everything on stack
## Complexity
Time: O(n * k) where k is the max repeat count  
Aux Space: O(n) for the stack
## Solution
```python
class Solution:
    def decodeString(self, s: str) -> str:

        stack = []

        for char in s:
            if char == "]":
                temp = []
                while stack[-1] != "[":
                    temp.append(stack.pop())
                
                stack.pop()

                count = []
                while stack and stack[-1].isnumeric():
                    count.append(stack.pop())

                count.reverse()
                count = int("".join(count))

                temp.reverse()
                stack.append("".join(temp * count))

            else:
                stack.append(char)
        
        return "".join(stack)
```
