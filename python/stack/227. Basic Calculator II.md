# 227. Basic Calculator II
## What I learned
* Operator precedence handled by stack: + and - push number, * and / immediately evaluate with stack top
* prev_op initialized to "+" so first number gets pushed correctly
* nonlocal lets nested functions modify enclosing scope variables — needed for reassignment not mutation
* Lists passed to nested functions are mutated in place (no nonlocal needed for stack)
* Process last number after loop ends — loop only triggers evaluation on operators
* int(a/b) truncates toward zero, // floors toward negative infinity — different for negatives
## Approach
1. Scan character by character building current number
2. On operator: evaluate using prev_op to decide how to push onto stack
3. After loop: evaluate remaining number
4. Return sum of stack
## Complexity
Time: O(n)  
Aux Space: O(n) for the stack
## Solution
```python
class Solution:
    def calculate(self, s: str) -> int:
        
        stack = []
        number = []
        prev_op = "+"

        def evaluate():
            nonlocal number, prev_op
            if prev_op == "+":
                stack.append(int("".join(number)))
            elif prev_op == "-":
                stack.append(int("".join(number)) * -1)
            elif prev_op == "*":
                stack.append(stack.pop() * int("".join(number)))
            elif prev_op == "/":
                stack.append(int(stack.pop() / int("".join(number))))

            number = []
            prev_op = char

        for char in s:
            if char.isdigit():
                number.append(char)
            elif char == " ":
                continue
            else:
                evaluate()

        evaluate()

        return sum(stack)
```
