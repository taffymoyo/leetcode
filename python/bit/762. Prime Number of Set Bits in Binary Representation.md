# 762. Prime Number of Set Bits in Binary Representation
## What I learned
* bit_count() returns number of 1 bits (Hamming weight) — added in Python 3.10, before that use bin(n).count('1')
* Since right <= 10^6 ≈ 2^20, bit count is at most 20 — hardcoding prime set {2,3,5,7,11,13,17,19} is valid
* bin(num)[2:] strips "0b" prefix, bin(num)[1:] only strips "0" — the "b" doesn't affect count but [2:] is correct
## Approach
1. For each number in [left, right], count its set bits
2. Check if that count is prime
3. Increment total if prime
## Complexity
Time: O(n) where n is right - left + 1 — prime check is O(1) since bit count ≤ 20  
Aux Space: O(1)
## Brute Force Solution (is_prime function)
```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:

        def is_prime(n: int) -> bool:
            if n < 2:
                return False
            for i in range(2, int(n**0.5) + 1):
                if n % i == 0:
                    return False
            return True

        total = 0
        for num in range(left, right + 1):
            bin_num = bin(num)[2:]
            one_count = bin_num.count("1")
            total += 1 if is_prime(one_count) else 0
        
        return total
```
## Optimised Solution (hardcoded prime set)
```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        primes = {2, 3, 5, 7, 11, 13, 17, 19}
        res = 0
        for i in range(left, right + 1):
            if i.bit_count() in primes:
                res += 1
        return res
```
