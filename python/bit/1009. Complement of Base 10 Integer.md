# 1009. Complement of Base 10 Integer
## What I learned
* Literally the same as 476. Number Complement — LeetCode has duplicate problems lol
## Approach
1. Convert n to binary string, strip "0b" prefix
2. Flip each bit: "1" → "0", "0" → "1"
3. Convert result back to int with base 2
## Complexity
Time: O(d) where d is the number of bits
Aux Space: O(d) for the result list
## Solution
```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        bin_num = bin(n)
        
        list_bin_num = list(bin_num)
        for i in range(2, len(list_bin_num)):
            if list_bin_num[i] == "1":
                list_bin_num[i] = "0"
            else:
                list_bin_num[i] = "1"
            
        list_bin_num = list_bin_num[2:]
        return int("".join(list_bin_num), 2)
```
