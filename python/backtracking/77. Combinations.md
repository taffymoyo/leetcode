# 77. Combinations
## What I learned
* For combinations, pass a start index to enforce increasing order — prevents duplicates without checking results list
* Pass `num` not `idx + 1` to the recursive call — they differ when numbers skip values
* Combinations don't need to check state of results list — just never go backwards in choices
## Approach
1. Backtrack building a path of length k
2. Only consider numbers greater than the last chosen (start from current num onwards)
3. When path length equals k, add a copy to results
## Complexity
Time: O(k * C(n,k)) — C(n,k) combinations each taking O(k) to copy  
Aux Space: O(k) for recursion stack depth
## Solution
```python
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:

        result = []
        def backtrack(path, idx):

            if len(path) == k:
                result.append(path[:])
                return

            for num in range(idx + 1, n + 1):
                path.append(num)
                backtrack(path, num)
                path.pop()

        backtrack([], 0)
        return result
```
