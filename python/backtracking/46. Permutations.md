# 46. Permutations
## What I learned
* Backtracking: pop() after recursion "undoes" the choice, allowing exploration of other branches
* The for loop at each level tries all remaining options — recursion handles depth, the loop handles breadth
* After base case is hit, the call stack unravels and the for loop continues with the next option
* Time complexity is O(n * n!) — n! permutations each taking O(n) to copy
## Approach
1. Build a path by appending numbers not already in the path
2. When path length equals nums length, add a copy to result
3. Pop after each recursive call to backtrack and try other options
## Complexity
Time: O(n * n!)  
Aux Space: O(n) for the recursion stack depth
## Solution
```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:

        result = []

        def backtrack(path):

            # base case
            if len(path) == len(nums):
                result.append(path[:])
                return
            
            for num in nums:
                if num not in path:
                    path.append(num)
                    backtrack(path)
                    path.pop()    
        
        backtrack([])
        return result
```
