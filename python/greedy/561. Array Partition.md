# 561. Array Partition
## What I learned
* Greedy pairing: sort and pair adjacent elements to maximise the sum of minimums
* After sorting, the minimum of each pair is always the left element, i initially was using the min function but decided not to for optimisation
* Sum of even indices after sorting gives the answer directly
## Approach
1. Sort nums in ascending order
2. Step through with step 2, accumulating every element at an even index (the smaller of each adjacent pair)
3. Return the accumulated sum
## Complexity
Time: O(n log n) dominated by sort
Aux Space: O(1)
## Solution
class Solution:
    def arrayPairSum(self, nums: List[int]) -> int:

        nums.sort()
        max_sum = 0

        i = 0
        while i < len(nums) - 1:
            max_sum += nums[i]
            i += 2
        
        return max_sum
