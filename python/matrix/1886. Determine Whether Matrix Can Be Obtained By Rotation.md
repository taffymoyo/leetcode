# 1886. Determine Whether Matrix Can Be Obtained By Rotation
## What I learned
* 90 degree clockwise rotation formula: new[j][n-1-i] = old[i][j]
* Must build a new matrix each rotation — modifying in place while reading causes overwrites
* new_mat[:] is a shallow copy — inner rows are still shared. Use [row[:] for row in new_mat] for a proper deep copy of a 2D list
* [[0]*n]*n creates shared row references — use [[0]*n for _ in range(n)] for independent rows
* _ convention: loop variable you don't need but still have to declare
## Approach
1. Try all 4 rotations (0°, 90°, 180°, 270°)
2. For each rotation build a new matrix using the formula new[j][n-1-i] = old[i][j]
3. Return True if any rotation matches target
## Complexity
Time: O(n²) per rotation × 4 rotations = O(n²)  
Aux Space: O(n²) for the new matrix
## Solution
```python
class Solution:
    def findRotation(self, mat: list[list[int]], target: list[list[int]]) -> bool:

        count, n = 0, len(mat)
        new_mat = [[0] * n for _ in range(n)]

        while count < 4:
            for i in range(n):
                for j in range(n):
                    new_mat[j][n - 1 - i] = mat[i][j]
            if new_mat == target:
                return True
            mat = [row[:] for row in new_mat]
            count += 1
        return False
```
