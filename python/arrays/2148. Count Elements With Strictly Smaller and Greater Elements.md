# 2148. Count Elements With Strictly Smaller and Greater Elements
## What I learned
* After sorting, nums[0] is the min and nums[-1] is the max — any element strictly between them counts
* Iterating from index 1 to len-2 naturally skips the first and last elements
## Approach
1. Sort the array
2. Count elements strictly greater than min (nums[0]) and strictly less than max (nums[-1])
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countElements(self, nums: list[int]) -> int:

        nums.sort()
        count = 0
        for i in range(1, len(nums) - 1):
            if nums[0] < nums[i] and nums[-1] > nums[i]:
                count += 1
        return count
```
