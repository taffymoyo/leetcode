# 2006. Count Number of Pairs With Absolute Difference K
## What I learned
* Same pattern as Two Sum — use hashmap to avoid nested loop
* Must check both num-k and num+k since absolute difference works both ways
* No double counting since hashmap only contains elements seen before current index
* hashmap.get(key, 0) cleanly handles missing keys without KeyError
## Approach
### Brute Force O(n²)
1. Check every pair (i,j) where i < j
2. Count pairs where absolute difference equals k
### Optimal O(n)
1. For each num, check if num-k or num+k already exists in hashmap
2. Add their frequencies to count
3. Add num to hashmap after checking
## Complexity
Brute Force — Time: O(n²), Aux Space: O(1)
Optimal — Time: O(n), Aux Space: O(n)
## Brute Force Solution
```python
class Solution:
    def countKDifference(self, nums: list[int], k: int) -> int:
        
        count = 0
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if abs(nums[i] - nums[j]) == k:
                    count += 1
        return count
```
## Optimised Solution
```python
class Solution:
    def countKDifference(self, nums: list[int], k: int) -> int:
        
        hashmap, count = {}, 0

        for num in nums:
            count += hashmap.get(num - k, 0)
            count += hashmap.get(num + k, 0)
            hashmap[num] = hashmap.get(num, 0) + 1
        
        return count
```
