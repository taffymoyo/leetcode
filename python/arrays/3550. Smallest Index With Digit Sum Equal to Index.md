# 3550. Smallest Index With Digit Sum Equal to Index
## What I learned
* More confident with digit extraction via % 10 and // 10 without string conversion
## Approach
1. For each index i, extract digits of nums[i] using repeated % 10 and // 10
2. Return i if digit sum equals i
3. Return -1 if no such index found
## Complexity
Time: O(n * d) where d is the number of digits per element  
Aux Space: O(1)
## Solution
```python
class Solution:
    def smallestIndex(self, nums: List[int]) -> int:

        for i, num in enumerate(nums):
            total = 0
            while num > 0:
                total += num % 10
                num //= 10
            if total == i:
                return i
        return -1
```
