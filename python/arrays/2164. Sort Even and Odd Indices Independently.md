# 2164. Sort Even and Odd Indices Independently
## What I learned
* sort(reverse=True) for descending order
* Separating elements by index parity, sorting independently, then interleaving
## Approach
1. Separate elements at even and odd indices into two lists
2. Sort even indices ascending, odd indices descending
3. Interleave them back together
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(n) for the two lists
## Solution
class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:

        even_list, odd_list, result = [], [], []

        i = 0
        while i < len(nums):
            even_list.append(nums[i])
            i += 1
            if i < len(nums):
                odd_list.append(nums[i])
                i += 1
            else:
                break

        even_list.sort()
        odd_list.sort(reverse=True)

        i = 0
        while i < len(even_list) or i < len(odd_list):
            if i < len(even_list):
                result.append(even_list[i])
            if i < len(odd_list):
                result.append(odd_list[i])
            i += 1
        
        return result
