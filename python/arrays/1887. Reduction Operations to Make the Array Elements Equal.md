# 1887. Reduction Operations to Make the Array Elements Equal
## What I learned
* Sorting reveals the insight: each element needs one operation per "level" it needs to drop through
* count tracks how many distinct levels we've seen — each new distinct value is a new level
* Every element at a higher level accumulates all the operations needed to pass through each level below it
## Approach
1. Sort nums
2. Track count of distinct value boundaries seen so far
3. For each element, add count to operations — representing how many level reductions it needs
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(1)
## Solution
```python
class Solution:
    def reductionOperations(self, nums: list[int]) -> int:
        
        count = 0
        nums.sort()
        operations = 0
        
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                count += 1

            operations += count

        return operations
```
