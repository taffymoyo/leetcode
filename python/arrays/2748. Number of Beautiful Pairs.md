# 2748. Number of Beautiful Pairs
## What I learned
* math.gcd(a, b) == 1 checks if two numbers are coprime
* First digit via str(num)[0], last digit via str(num)[-1]
## Approach
1. For every pair (i, j) where i < j, extract the first digit of nums[i] and last digit of nums[j]
2. Check if they are coprime using math.gcd
3. Increment count if gcd == 1
## Complexity
Time: O(n²)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countBeautifulPairs(self, nums: List[int]) -> int:

        count = 0
        for i in range(len(nums) - 1):
            for j in range(i + 1, len(nums)):
                str_num1, str_num2 = str(nums[i]), str(nums[j])
                if math.gcd(int(str_num1[0]), int(str_num2[-1])) == 1:
                    count += 1
        return count
```
