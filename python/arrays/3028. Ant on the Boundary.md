# 3028. Ant on the Boundary

## What I learned
Nothing the question was relatively simple

## Approach
1. Have a starting position of 0
2. Add the numbers, if the position after adding is == 0 update the count
3. Return the count

## Complexity
Time: O(n)
Aux Space: O(1)

## Solution
class Solution:
    def returnToBoundaryCount(self, nums: List[int]) -> int:

        position = 0
        count = 0

        for num in nums:
            position += num
            if position == 0:
                count += 1
        
        return count
