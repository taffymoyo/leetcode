# 1608. Special Array With X Elements Greater Than or Equal X
## What I learned
* bisect_left(nums, x) returns the leftmost insertion index for x in a sorted array
* len(nums) - bisect_left(nums, x) gives the count of elements >= x in O(log n)
* Binary search only helps when you know the library — the O(n²) logic was correct from the start
## Approach
1. For each x from 1 to len(nums), count how many elements are >= x
2. Return x if count equals x, otherwise return -1
## Complexity
Time: O(n²)  
Aux Space: O(1)
## Solution
class Solution:
    def specialArray(self, nums: List[int]) -> int:

        for x in range(1, len(nums) + 1):
            count = 0
            for num in nums:
                if num >= x:
                    count += 1
            if count == x:
                return x
        
        return -1

## Optimised Solution (bisect)
Uses binary search to reduce per-x count from O(n) to O(log n)
```python
from bisect import bisect_left

class Solution:
    def specialArray(self, nums: List[int]) -> int:
        nums.sort()
        
        for x in range(1, len(nums) + 1):
            count = len(nums) - bisect_left(nums, x)
            if count == x:
                return x
        
        return -1
```
