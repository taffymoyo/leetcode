# 3289. The Two Sneaky Numbers of Digitville

## What I learned

Sets give O(1) look up time, makes the time complexity of the solution better

## Approach

1. Have a set that tracks numbers already seen
2. If a number has already been seen append it to the result

## Complexity

Time: O(n)  
Aux Space: O(n)

## Solution

class Solution:
    def getSneakyNumbers(self, nums: List[int]) -> List[int]:
        seen = set()
        result = []
        
        for num in nums:
            if num in seen:
                result.append(num)
            else:
                seen.add(num)
        
        return result
