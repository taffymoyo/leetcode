# 1560. Most Visited Sector in a Circular Track
## What I learned
* Mixing a 0-indexed pointer with 1-indexed sector values causes off-by-one bugs. Comment which indexing each variable uses
* Wraparound: j = (j + 1) % n moves the pointer and wraps in one step. Setting j = 0 and then doing j += 1 skips a sector
* Two ways to avoid double counting the sector shared between rounds: count the start and skip the end (then add the final sector after the loops), or count the end and skip the start
* Every full lap visits every sector equally, so only the stretch from rounds[0] to rounds[-1] decides which sectors are visited most
## Approach
### Simulation
1. Walk the track round by round with a 0-indexed pointer
2. Count each sector from the start of a round up to but not including its end, since the next round counts that sector as its start
3. Count the final sector once after the loops
4. Return every sector whose count equals the max, 1-indexed
### Shortcut
1. Full laps add the same amount to every sector, so ignore them
2. Only the path from rounds[0] to rounds[-1] gets an extra visit
3. If rounds[0] <= rounds[-1], return the range between them. Otherwise the path wraps, so return 1 to rounds[-1] plus rounds[0] to n
## Complexity
Simulation: Time O(n * m) where m is len(rounds), Aux Space O(n)
Shortcut: Time O(n), Aux Space O(1) excluding the output
## Simulation Solution
```python
class Solution:
    def mostVisited(self, n: int, rounds: list[int]) -> list[int]:

        visited = [0] * n

        j = rounds[0] - 1  # 0-indexed
        for i in range(len(rounds) - 1):
            target = rounds[i + 1] - 1  # 0-indexed
            while j != target:
                visited[j] += 1
                j = (j + 1) % n

        visited[j] += 1  # final sector

        most = max(visited)
        return [i + 1 for i, v in enumerate(visited) if v == most]
```
## Shortcut Solution
```python
class Solution:
    def mostVisited(self, n: int, rounds: list[int]) -> list[int]:

        start, end = rounds[0], rounds[-1]

        if start <= end:
            return list(range(start, end + 1))

        return list(range(1, end + 1)) + list(range(start, n + 1))
```
