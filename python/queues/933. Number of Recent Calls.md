# 933. Number of Recent Calls
## What I learned
* deque is the right data structure when you need to add to one end and remove from the other (FIFO)
* popleft() removes from front, append() adds to back
* Store timestamps as they arrive, remove ones outside the 3000ms window from the front
## Approach
1. Append the new timestamp to the deque
2. Remove from the front any timestamps older than t - 3000
3. Return the length of the deque — everything remaining is within the window
## Complexity
Time: O(1) amortised — each timestamp is added and removed at most once  
Aux Space: O(n) where n is the number of requests in the 3000ms window
## Solution
```python
from collections import deque

class RecentCounter:

    def __init__(self):
        self.requests = deque()

    def ping(self, t: int) -> int:
        self.requests.append(t)

        while self.requests[0] < t - 3000:
            self.requests.popleft()

        return len(self.requests)
```
