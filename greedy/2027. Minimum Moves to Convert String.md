# 2027. Minimum Moves to Convert String
## What I learned
* Greedy: always cover the leftmost X with a window of 3, then skip ahead 3
* Modifying the array in place and checking last 2 separately works but the while loop with i += 3 is cleaner
* Those are O's not 0's 😭
## Approach
1. Scan left to right, when an X is found cover it with a window of 3 (set next 3 to O)
2. Skip ahead 3 indices since they're now covered
3. Otherwise advance by 1
## Complexity
Time: O(n)
Aux Space: O(1)
## Solution
```python
class Solution:
    def minimumMoves(self, s: str) -> int:

        count = 0
        result = list(s)

        for i in range(len(result) - 2):
            if result[i] != "O": 
                result[i], result[i + 1], result[i + 2] = "O", "O", "O"
                count += 1

        if result[-1] != "O" or result[-2] != "O":
            count += 1

        return count
```
