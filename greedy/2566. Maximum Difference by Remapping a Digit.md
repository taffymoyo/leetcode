# 2566. Maximum Difference by Remapping a Digit
## What I learned
* str.replace(old, new) replaces all occurrences of a substring in one call (I learnt this after my manual loop solution after looking at other peoples)  
* For max: replace the first non-9 digit with 9 everywhere
* For min: replace the first digit with 0 everywhere
## Approach
1. For the maximum: scan left to right, find the first digit that isn't 9, replace all occurrences of it with 9
2. For the minimum: replace all occurrences of the first digit with 0
3. Return max - min
## Complexity
Time: O(n) where n is the number of digits
Aux Space: O(n) for the digit arrays
## Solution
class Solution:
    def minMaxDifference(self, num: int) -> int:

        arr_num = list(str(num))
        arr_num2 = arr_num[:]
        replacement_digit = None

        i = 0
        while i < len(arr_num):
            if replacement_digit:
                if arr_num[i] == replacement_digit:
                    arr_num[i] = "9"
            else:
                if arr_num[i] != "9":
                    replacement_digit = arr_num[i]
                    arr_num[i] = "9"
            i += 1

        max_num = int("".join(arr_num))

        replacement_digit = None
        i = 0
        while i < len(arr_num2):
            if replacement_digit:
                if arr_num2[i] == replacement_digit:
                    arr_num2[i] = "0"
            else:
                if arr_num2[i] != "0":
                    replacement_digit = arr_num2[i]
                    arr_num2[i] = "0"
            i += 1

        min_num = int("".join(arr_num2))

        return max_num - min_num
