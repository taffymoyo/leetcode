# 2578. Split With Minimum Sum
## What I learned
* Greedy + place value: largest digits should end up in the lowest place values to minimise sum
* Alternating assignment ensures both numbers grow at the same rate, preventing one number from accumulating high digits in high place positions (I kinda deduced this from the example cases)
## Approach
1. Sort the digits of num in ascending order
2. Alternate assigning digits to num1 and num2 (even indices → num1, odd indices → num2)
3. Convert both back to integers and return their sum
## Complexity
Time: O(n log n) where n is the number of digits (dominated by sort)  
Aux Space: O(n) for the two digit arrays
## Solution
class Solution:
    def splitNum(self, num: int) -> int:
        
        num1, num2, = [], []
        sorted_nums = sorted(str(num))

        for i, num in enumerate(sorted_nums):
            if i % 2 == 0:
                num1.append(num)
            else:
                num2.append(num)
        
        return int("".join(num1)) + int("".join(num2))
