# 2037. Minimum Number of Moves to Seat Everyone
## What I learned
* Greedy pairing: sort both arrays and pair by rank — smallest seat with smallest student position minimises total movement
* Same insight as the array partition problem — matching sorted orders is always optimal
## Approach
1. Sort both seats and students
2. Pair each seat with the corresponding student by index
3. Sum absolute differences
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(n) for sorted copies
## Solution
```python
class Solution:
    def minMovesToSeat(self, seats: list[int], students: list[int]) -> int:

        count, sorted_seats, sorted_students = 0, sorted(seats), sorted(students)

        for i, seat in enumerate(sorted_seats):
            count += abs(seat - sorted_students[i])
        
        return count
```
