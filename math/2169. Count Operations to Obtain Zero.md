# 2169. Count Operations to Obtain Zero
## What I learned
* This is essentially the Euclidean algorithm but with subtraction instead of modulo — much slower but same concept
* while num1 and num2 > 0 has a subtle bug — should be while num1 > 0 and num2 > 0 since "num1 and num2 > 0" evaluates as "num1 and (num2 > 0)" due to operator precedence
## Approach
1. While both numbers are non-zero, subtract the smaller from the larger
2. Increment count each operation
3. Return count when either hits 0
## Complexity
Time: O(max(num1, num2)) in worst case — subtraction is slow, modulo version would be O(log)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def countOperations(self, num1: int, num2: int) -> int:
        
        count = 0
        while num1 > 0 and num2 > 0:
            if num1 >= num2:
                num1 -= num2
            else:
                num2 -= num1
            count += 1

        return count
```
