# 3131. Find the Integer Added to Array I
## What I learned
* sum(nums2) - sum(nums1) gives the total amount added across all elements
* Dividing by len gives x since x was added to every element uniformly
* O(n) sum approach beats O(n log n) sorting approach
## Approach
1. The total difference in sums equals x * n since x was added to every element
2. Divide by n to get x
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
class Solution:
    def addedInteger(self, nums1: List[int], nums2: List[int]) -> int:  
        return int((sum(nums2) - sum(nums1)) / len(nums1))
