# 2544. Alternating Digit Sum
## What I learned
* Alternating sign pattern: even indices add, odd indices subtract
* i % 2 == 0 cleanly handles the alternating sign without needing a separate flag
## Approach
1. Convert n to a string to iterate over digits
2. Add digits at even indices, subtract digits at odd indices
3. Return the total
## Complexity
Time: O(d) where d is the number of digits in n
Aux Space: O(d) for the string conversion
## Solution
class Solution:
    def alternateDigitSum(self, n: int) -> int:
        
        total = 0
        str_n = str(n)
        for i in range(len(str_n)):
            if i % 2 == 0:
                total += int(str_n[i])
            else:
                total -= int(str_n[i])
    
        return total
