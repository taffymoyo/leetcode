# 2119. A Number After a Double Reversal
## What I learned
* Key insight: a number can only survive double reversal if it doesn't end in 0 (trailing zeros are lost on first reversal)
* 0 is a special case — it's still 0 after any number of reversals
* Sometimes the trick is to find what makes it impossible rather than simulating the operation
## Approach
1. If num is 0, return True (0 reversed is still 0)
2. If num ends in 0 (num % 10 == 0), return False — trailing zero lost on first reversal means you can never recover original
3. Otherwise return True
## Complexity
Time: O(1)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def isSameAfterReversals(self, num: int) -> bool:
        return num % 10 != 0 if num > 0 else True
```
