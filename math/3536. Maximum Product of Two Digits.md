# 3536. Maximum Product of Two Digits
## What I learned
* Initialising tracking variables at -1 is safe when values are guaranteed non-negative — no digit can be negative so -1 will always be replaced
* More confident with digit-by-digit extraction using % 10 and // 10 without string conversion
## Approach
1. Extract digits one by one using repeated % 10 and // 10
2. Track the two largest digits seen so far
3. Return their product
## Complexity
Time: O(d) where d is the number of digits  
Aux Space: O(1)  
(yeah I did it without sorting cuz im the goat)

## Solution
```python
class Solution:
    def maxProduct(self, n: int) -> int:
        
        largest, second_largest = -1, -1
        
        while n > 0:
            digit = n % 10
            if digit > largest:
                second_largest = largest
                largest = digit
            elif digit > second_largest:
                second_largest = digit
            
            n //= 10

        return largest * second_largest
```
