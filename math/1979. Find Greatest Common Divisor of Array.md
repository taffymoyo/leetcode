# 1979. Find Greatest Common Divisor of Array
## What I learned
* Euclidean algorithm: gcd(a,b) = gcd(b, a%b) — GCD is preserved because any common factor of a and b must also divide the remainder
* Python evaluates the right side of simultaneous assignment completely before assigning — so smallest, largest = largest, smallest % largest uses original values
* elif when finding min/max causes bugs — use two separate if statements
* When b=0, a is the GCD since a divided the previous b with no remainder
## Approach
1. Find smallest and largest elements in nums
2. Apply Euclidean algorithm to find their GCD
## Complexity
Time: O(n + log(min(a,b))) — O(n) to find min/max, O(log) for GCD  
Aux Space: O(1)
## Solution
```python
class Solution:
    def findGCD(self, nums: list[int]) -> int:

        smallest, largest = min(nums), max(nums)
        
        while largest:
            smallest, largest = largest, smallest % largest
        return smallest
```
