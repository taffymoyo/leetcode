# 367. Valid Perfect Square
## What I learned
* Binary search on the answer space — search for integer z where z*z == num
* Two valid binary search styles:
  * Inclusive [l, r]: while l <= r, r = x - 1
  * Exclusive [l, r): while l < r, r = x (not r = x - 1)
* l + (r-l)//2 avoids integer overflow vs (l+r)//2 — good habit from C/Java even though Python handles big ints fine
## Approach
1. Binary search range [0, num]
2. For midpoint x, check if x*x == num
3. If x*x < num, search right; if x*x > num, search left
## Complexity
Time: O(log n)  
Aux Space: O(1)
## Inclusive Solution
```python
class Solution:
    def isPerfectSquare(self, num: int) -> bool:

        l, r = 0, num
        while l <= r:
            x = (l + r) // 2
            if x * x == num:
                return True
            elif x * x < num:
                l = x + 1
            else:
                r = x - 1
        return False
```
## Exclusive Solution
```python
class Solution:
    def isPerfectSquare(self, num: int) -> bool:

        l, r = 0, num + 1
        while l < r:
            x = (l + r) // 2
            if x * x == num:
                return True
            elif x * x < num:
                l = x + 1
            else:
                r = x
        return False
```
