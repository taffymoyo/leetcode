# 371. Sum of Two Integers
## What I learned
* str(negative)[1:] strips the minus sign without using the - operator — creative workaround
* To reconstruct a negative result, prepend the sign character from the original negative number
* The intended solution uses bit manipulation (XOR for sum, AND+shift for carry) but string manipulation is a valid creative approach
## Approach
1. Build positive and negative result lists by appending to ranges
2. Cancel out positives and negatives by popping from both lists
3. Return length of remaining list with appropriate sign
## Complexity
Time: O(|a| + |b|)  
Aux Space: O(|a| + |b|) for the lists
## Solution
```python
class Solution:
    def getSum(self, a: int, b: int) -> int:

        pos_res = []
        neg_res = []

        if a > 0:
            for i in range(a):
                pos_res.append(i)
        if b > 0:
            for i in range(b):
                pos_res.append(i)
        if a < 0:
            str_a = str(a)
            neg_range = int(str_a[1:])
            for i in range(neg_range):
                neg_res.append(i)
        if b < 0:
            str_b = str(b)
            neg_range = int(str_b[1:])
            for i in range(neg_range):
                neg_res.append(i)

        if a > 0 and b > 0:
            return len(pos_res)
        if a < 0 and b < 0:
            neg_length = len(neg_res)
            neg = int(f"{str_b[0]}{neg_length}")
            return neg
        
        while neg_res and pos_res:
            pos_res.pop()
            neg_res.pop()
        
        if len(neg_res) == 0:
            return len(pos_res)
        else:
            str_neg = str(b) if b < 0 else str(a)
            str_neg = f'{str_neg[0]}{len(neg_res)}'
            return int(str_neg)
```
