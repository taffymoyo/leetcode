# 2769. Find the Maximum Achievable Number
## What I learned
* Each operation shrinks the gap between x and num by 2 — so t operations close a gap of 2t
* Maximum x is num + 2t since we want x as large as possible
## Approach
1. To maximise x, start it as high as possible
2. Each operation: x decreases by 1, num increases by 1 — gap closes by 2
3. After t operations, gap closed by 2t, so max x = num + 2t
## Complexity
Time: O(1)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def theMaximumAchievableX(self, num: int, t: int) -> int:
        return num + t + t
```
