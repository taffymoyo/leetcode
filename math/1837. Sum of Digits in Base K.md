# 1837. Sum of Digits in Base K
## What I learned
* Converting base 10 to another base is the same repeated division pattern as digit extraction — just divide by k instead of 10
* Digits come out least significant first — but here we don't need to reverse since we're just summing them
## Approach
1. Repeatedly divide n by k, accumulating remainders (which are the base-k digits)
2. Return the sum of all digits
## Complexity
Time: O(log_k(n)) — number of digits in base k  
Aux Space: O(1)
## Solution
```python
class Solution:
    def sumBase(self, n: int, k: int) -> int:

        count = 0
        while n > 0:
            count += n % k
            n //= k
        return count
```
