# 1925. Count Square Sum Triples
## What I learned
* There's no closed-form formula for this one, but the third loop can be removed by computing c directly instead of searching for it
* math.isqrt(x) returns the floor of the square root as an exact int, with no float error
* isqrt always returns a whole number, even when the real root isn't whole (isqrt(13) = 3), so multiplying back (c * c == a² + b²) is what checks that it was a perfect square
* Check c <= n so the hypotenuse stays inside the allowed range
## Approach
### Brute Force O(n³)
1. Try every (a, b, c) with 1 <= a, b, c <= n
2. Count it if a² + b² == c²
### Optimised O(n²)
1. Loop over every (a, b) pair
2. Compute c = isqrt(a² + b²), the only possible candidate
3. Count it if c <= n and c² == a² + b²
## Complexity
Brute Force: Time O(n³), Aux Space O(1)
Optimised: Time O(n²), Aux Space O(1)
## Brute Force Solution
```python
class Solution:
    def countTriples(self, n: int) -> int:

        count = 0
        for a in range(1, n + 1):
            for b in range(1, n + 1):
                for c in range(1, n + 1):
                    if (a**2 + b**2) == c**2:
                        count += 1
        return count
```
## Optimised Solution
```python
from math import isqrt

class Solution:
    def countTriples(self, n: int) -> int:

        count = 0
        for a in range(1, n + 1):
            for b in range(1, n + 1):
                c = isqrt(a**2 + b**2)
                if c <= n and c**2 == a**2 + b**2:
                    count += 1
        return count
```
