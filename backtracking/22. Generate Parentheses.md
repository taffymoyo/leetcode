# 22. Generate Parentheses
## What I learned
* Backtracking with constraints: open brackets can always be added up to n, closed brackets can only be added when closed < open (ensures validity)
* No need to check all combinations and filter — constraints naturally prune invalid paths
* Chained comparisons: open_p == closed_p == n checks all three are equal
## Approach
1. Backtrack tracking open and closed bracket counts
2. Add '(' if open < n
3. Add ')' only if closed < open (can't close what isn't open) and closed < n
4. Base case: when open == closed == n, add the completed string to results
## Complexity
Time: O(4^n / √n) — Catalan number, the number of valid parentheses combinations  
Aux Space: O(n) for recursion stack depth
## Solution
```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        
        result = []

        def backtrack(path, open_p, closed_p):

            if open_p == closed_p == n:
                result.append("".join(path[:]))
                return
            
            if open_p < n:
                path.append("(")
                backtrack(path, open_p + 1, closed_p)
                path.pop()
            
            if closed_p < n and closed_p < open_p:
                path.append(")")
                backtrack(path, open_p, closed_p + 1)
                path.pop()
        
        backtrack([], 0, 0)
        return result
```
