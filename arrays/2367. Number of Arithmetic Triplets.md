# 2367. Number of Arithmetic Triplets
## What I learned
* Because nums is strictly increasing, a triplet is fully determined by its last element: if nums[i] - diff and nums[i] - 2*diff both exist, the triplet is valid
* A set gives O(1) membership checks, which replaces the two inner loops of the brute force
* Same idea as the hashmap approach in Count Pairs With Absolute Difference K: store what you've seen so you can look it up instead of searching
## Approach
### Brute Force O(n³)
1. Try every triplet i < j < k
2. Count it if nums[k] - nums[j] == diff and nums[j] - nums[i] == diff
### Optimal O(n)
1. Put all numbers in a set
2. For each number, check whether num - diff and num - 2*diff are both in the set
3. If so, it is the last element of a valid triplet, so increment count
## Complexity
Brute Force: Time O(n³), Aux Space O(1)
Optimal: Time O(n), Aux Space O(n) for the set
## Brute Force Solution
```python
class Solution:
    def arithmeticTriplets(self, nums: list[int], diff: int) -> int:

        count, n = 0, len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[k] - nums[j] == diff and nums[j] - nums[i] == diff:
                        count += 1
        return count
```
## Optimised Solution
```python
class Solution:
    def arithmeticTriplets(self, nums: list[int], diff: int) -> int:

        num_set = set(nums)
        count = 0
        for num in nums:
            if num - diff in num_set and num - 2 * diff in num_set:
                count += 1
        return count
```
