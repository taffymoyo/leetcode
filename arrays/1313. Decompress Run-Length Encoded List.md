# 1313. Decompress Run-Length Encoded List
## What I learned
* not i % 2 is a clean way to check even indices (equivalent to i % 2 == 0)
* Run-length encoding: pairs of (frequency, value) — even index is count, odd index is value
## Approach
1. Iterate through pairs — even index stores the frequency, odd index stores the value
2. Append the value freq times to result
## Complexity
Time: O(n * max_freq) where max_freq is the largest frequency value  
Aux Space: O(n * max_freq) for the result
## Solution
```python
class Solution:
    def decompressRLElist(self, nums: list[int]) -> list[int]:
        
        result = []
        for i, num in enumerate(nums):
            if not i % 2:
                count = num
            else:
                while count:
                    result.append(nums[i])
                    count -= 1
        
        return result
```
