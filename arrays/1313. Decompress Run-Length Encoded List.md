# 1313. Decompress Run-Length Encoded List
## What I learned
* not i % 2 is a clean way to check even indices (equivalent to i % 2 == 0)
* extend([val] * count) appends count copies of val without a while loop — cleaner than manual iteration
* extend takes an iterable and adds each element individually, [val] * count creates a list of count copies
## Approach
1. Iterate through pairs — even index stores the frequency, odd index stores the value
2. Extend result with count copies of the value
## Complexity
Time: O(n * max_freq)  
Aux Space: O(n * max_freq) for the result
## Solution
```python
class Solution:
    def decompressRLElist(self, nums: list[int]) -> list[int]:
        
        result = []
        for i, num in enumerate(nums):
            if not i % 2:
                count = num
            else:
                result.extend([nums[i]] * count)
        
        return result
```
