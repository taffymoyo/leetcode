# 2144. Minimum Cost of Buying Candies With Discount
## What I learned
* Greedy: sort descending, every 3rd candy (index 2, 5, 8...) is free
* Buying the two most expensive first maximises the free candy's value
## Approach
1. Sort descending
2. Skip every 3rd candy (count resets after 2 paid candies)
3. Sum all paid candies
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(1)
## Solution
```python
class Solution:
    def minimumCost(self, cost: list[int]) -> int:

        cost.sort()

        total = 0
        n = len(cost)
        count = 0

        for i in range(n - 1, -1, -1):
            if count < 2:
                total += cost[i]
                count += 1
            else:
                count = 0         
        
        return total
```
