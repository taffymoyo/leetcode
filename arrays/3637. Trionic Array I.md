# 3637. Trionic Array I
## What I learned
* Boundary conditions with exclusive indices (0 < p < q < n-1) mean the loop ranges must be carefully bounded
* Overlapping slices at split points — nums[0:p+1] and nums[p:q+1] share index p
* Don't need a triple loop when one index is always fixed at 0
## Approach
1. Try all valid split points j (p) and k (q) where 1 <= j < k <= n-2
2. Check if nums[0:j+1] is strictly increasing, nums[j:k+1] is strictly decreasing, nums[k:] is strictly increasing
3. Return True if any valid split is found
## Complexity
Time: O(n³) — two loops plus O(n) check per iteration
Aux Space: O(n) for slices
## Solution
```python
class Solution:
    def isTrionic(self, nums: List[int]) -> bool:   

        def increasing(arr) -> bool:
            for i in range(len(arr) - 1):
                if arr[i + 1] <= arr[i]:
                    return False
            return True
        
        def decreasing(arr) -> bool:
            for i in range(len(arr) - 1):
                if arr[i + 1] >= arr[i]:
                    return False
            return True

        for j in range(1, len(nums)):
            for k in range(j + 1, len(nums) - 1):
                if increasing(nums[:j+1]) and decreasing(nums[j:k+1]) and increasing(nums[k:]):
                    return True
        return False
```
