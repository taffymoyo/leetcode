# 1995. Count Special Quadruplets
## What I learned
* nums[a]+nums[b]+nums[c]==nums[d] can be rewritten as nums[a]+nums[b]==nums[d]-nums[c] — rearranging equations opens up hashmap optimisation
* Precomputing pair sums into a hashmap reduces the search from O(n⁴) to O(n²)
* For n≤50 brute force O(n⁴) is perfectly acceptable — always check constraints before optimising
## Approach
### Brute Force O(n⁴)
1. Four nested loops with increasing indices a < b < c < d
2. Check if nums[a] + nums[b] + nums[c] == nums[d]
### Optimised O(n²)
1. Rewrite as nums[a] + nums[b] == nums[d] - nums[c]
2. For each c, precompute all (a,b) pair sums where b = c-1 into a hashmap
3. For each d > c, check if nums[d] - nums[c] exists in the map
## Complexity
Brute Force — Time: O(n⁴), Aux Space: O(1)  
Optimised — Time: O(n²), Aux Space: O(n)
## Brute Force Solution
```python
class Solution:
    def countQuadruplets(self, nums: list[int]) -> int:

        n, count = len(nums), 0
        for a in range(n):
            for b in range(a + 1, n):
                for c in range(b + 1, n):
                    for d in range(c + 1, n):
                        if nums[a] + nums[b] + nums[c] == nums[d]:
                            count += 1
        
        return count
```
## Optimised Solution
```python
class Solution:
    def countQuadruplets(self, nums: list[int]) -> int:
        
        hmap = defaultdict(int)
        ans = 0

        for c in range(2, len(nums) - 1):
            b = c - 1
            for a in range(b):
                hmap[nums[a] + nums[b]] += 1
            
            for d in range(c + 1, len(nums)):
                ans += hmap[nums[d] - nums[c]]
        
        return ans
```
