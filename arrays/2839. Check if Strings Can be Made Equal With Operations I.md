# 2839. Check if Strings Can be Made Equal With Operations I
## What I learned
* Swaps between fixed index pairs (0,2) and (1,3) mean only the set of characters at those positions matters, not their order
* Sorting gives a canonical form to compare unordered pairs
## Approach
1. Check if the characters at even indices (0, 2) are the same multiset in both strings
2. Check if the characters at odd indices (1, 3) are the same multiset in both strings
3. Return True only if both checks pass
## Complexity
Time: O(1) — string is always length 4  
Aux Space: O(1)
## Solution
class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        return (sorted([s1[0], s1[2]]) == sorted([s2[0], s2[2]]) and
                sorted([s1[1], s1[3]]) == sorted([s2[1], s2[3]]))
