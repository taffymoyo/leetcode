# 2200. Find All K-Distant Indices in an Array
## What I learned
* Collect the indices where nums[j] == key first, then check every index i against them
* break after the first match stops the inner loop early, so each i is appended at most once and the result stays in ascending order
* The inner loop over keys makes this O(n * m), so it can be improved by sweeping once and using a pointer
## Approach
1. Loop through nums and record every index where the value equals key
2. For each index i, check whether any key index is within distance k
3. If so, append i to the result and break, so i isn't added twice
## Complexity
Time: O(n * m) where m is the number of key indices (worst case O(n²))  
Aux Space: O(m) for the keys list
## Solution
```python
class Solution:
    def findKDistantIndices(self, nums: list[int], key: int, k: int) -> list[int]:
        
        result = []
        keys = []

        for i, num in enumerate(nums):
            if num == key:
                keys.append(i)
        
        for i, num in enumerate(nums):
            for key_i in keys:
                if abs(i - key_i) <= k:
                    result.append(i)
                    break
        
        return result
```
