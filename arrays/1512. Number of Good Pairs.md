# 1512. Number of Good Pairs
## What I learned
* For counting pairs with equal values, Counter can reduce to O(n) — for each value with frequency f, there are f*(f-1)/2 pairs
* Brute force O(n²) is fine here given small constraints
## Approach
1. For every pair (i,j) where i < j, check if nums[i] == nums[j]
2. Increment count if equal
## Complexity
Time: O(n²)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def numIdenticalPairs(self, nums: list[int]) -> int:

        count = 0
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] == nums[j]:
                    count += 1
        
        return count
```
