# 3010. Divide an Array Into Subarrays With Minimum Cost I
## What I learned
* nums[0] is always the cost of the first subarray — only need to minimize the next two
* Track two smallest values from nums[1:] using running minimums
* Initializing to 51 works since constraints guarantee nums[i] <= 50
## Approach
1. First subarray cost is always nums[0]
2. Find the two smallest values in nums[1:] for the other two subarray costs
3. Return sum of all three
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def minimumCost(self, nums: List[int]) -> int:

        count = nums[0]
        
        second, third = 51, 51
        for i in range(1, len(nums)):
            if nums[i] < second:
                third = second
                second = nums[i]
            elif nums[i] < third:
                third = nums[i]
        
        return count + second + third
```
