## Approach
1. Make a dictionary of the available digits
2. Loop over all available numbers in range [100,998] with a step of 2 (only considers even numbers and halves the number of iterations)
3. Unpack the digits in these 3 digit numbers and check if each digit is available for use, if it is then it is added to the result list to be returned at the end.

## Complexity
Time: O(n) where n is the size of the digit list  
Aux Space: O(n) where n is the size of the digit list

## Solution
class Solution:
    def findEvenNumbers(self, digits: List[int]) -> List[int]:

        result = []
        seen = Counter(digits)

        for num in range(100, 999, 2):
            available = seen.copy()
            string_num = str(num)
            individual_digits = int(string_num[0]), int(string_num[1]), int(string_num[2])

            for digit in individual_digits:
                available[digit] -= 1
                if available[digit] < 0:
                    break
            else:
                result.append(num)
        
        return result
