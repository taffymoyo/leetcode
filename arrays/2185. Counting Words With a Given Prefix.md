# 2185. Counting Words With a Given Prefix
## What I learned
* String slicing word[:len(pref)] == pref is a clean way to check prefixes
* Alternatively str.startswith(pref) does the same thing more readably
## Approach
1. For each word, check if its first len(pref) characters match pref
2. Increment count if they match
## Complexity
Time: O(n * m) where n is number of words and m is length of pref  
Aux Space: O(1)
## Solution
```python
class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:

        prefix_len = len(pref)
        count = 0

        for word in words:
            if len(word) >= prefix_len:
                if word[:prefix_len] == pref:
                    count += 1
        return count
```
