# 2778. Sum of Squares of Special Elements
## What I learned
* 1-indexed problem — iterate i from 1 to n inclusive, access nums[i-1]
* Special element: index i (1-indexed) divides n, i.e. n % i == 0
## Approach
1. Iterate i from 1 to len(nums) inclusive
2. If n % i == 0, add nums[i-1]² to total
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:

        total = 0

        for i in range(1, len(nums) + 1):
            if len(nums) % i == 0:
                total += nums[i - 1] * nums[i - 1]
        
        return total
```
