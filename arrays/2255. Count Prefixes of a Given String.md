# 2255. Count Prefixes of a Given String
## What I learned
* Slicing s[:len(word)] gives the first len(word) characters of s, so comparing it to word checks the prefix directly
* If word is longer than s, the slice just returns all of s, so the comparison fails naturally with no extra bounds check
* str.startswith() does the same job: s.startswith(word)
## Approach
1. For each word, slice s down to the same length
2. If the slice equals the word, it is a prefix of s, so increment count
3. Return count
## Complexity
Time: O(n * m) where n is the number of words and m is the max word length  
Aux Space: O(m) for the slice created on each iteration
## Solution
```python
class Solution:
    def countPrefixes(self, words: list[str], s: str) -> int:
        
        count = 0
        for word in words:
            length = len(word)
            if word == s[:length]:
                count += 1
        return count
```
