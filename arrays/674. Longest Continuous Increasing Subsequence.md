# 674. Longest Continuous Increasing Subsequence
## What I learned
* Track current streak and max streak — reset current on break
* Edge case: if the longest streak is at the end of the array, the final max comparison outside the loop handles it
## Approach
1. Track current increasing streak length
2. Reset to 1 when streak breaks, update max at that point
3. Return max of current and max at the end to handle trailing streaks
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def findLengthOfLCIS(self, nums: list[int]) -> int:

        current_count, max_count = 1, 1

        for i, num in enumerate(nums):
            if i < len(nums) - 1:
                if nums[i + 1] > num:
                    current_count += 1
                else:
                    max_count = max(current_count, max_count)
                    current_count = 1
        
        return current_count if current_count > max_count else max_count
```
