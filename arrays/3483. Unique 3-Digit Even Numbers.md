# 3483. Unique 3-Digit Even Numbers
## What I learned
* Using a seen set to deduplicate permutations before counting
* Leading zero check: first digit (i) must not be 0
* Even check: last digit (k) must be even — or just check str_num % 2 == 0
## Approach
1. Triple nested loop with distinct indices i, j, k
2. Skip if i is 0 (leading zero)
3. Build the 3-digit number as a string, check if even and not already seen
4. Add to seen set and increment count
## Complexity
Time: O(n³) where n is len(digits), bounded by constant since digits ≤ 9  
Aux Space: O(1) — at most 900 unique 3-digit even numbers in the set
## Solution
```python
class Solution:
    def totalNumbers(self, digits: List[int]) -> int:

        count = 0
        seen = set()
        
        for i in range(len(digits)):
            if digits[i] != 0:
                for j in range(len(digits)):
                    for k in range(len(digits)):
                        if i != j and i != k and j != k:
                            str_num = str(digits[i]) + str(digits[j]) + str(digits[k])
                            if int(str_num) % 2 == 0 and str_num not in seen:
                                seen.add(str_num)
                                count += 1
        return count
```
