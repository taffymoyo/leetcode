# 2460. Apply Operations to an Array
## What I learned
* Operations must be applied sequentially, not simultaneously
* Zero-shifting can be done in one pass by collecting non-zeros then appending zeros at the end
## Approach
1. Apply n-1 operations sequentially: if nums[i] == nums[i+1], double nums[i] and zero nums[i+1]
2. Collect all non-zero elements into a new array, count the zeros
3. Append the zeros to the end
## Complexity
Time: O(n)  
Aux Space: O(n) for the result array
## Solution
class Solution:
    def applyOperations(self, nums: List[int]) -> List[int]:

        array = []
        zero_count = 0

        i = 0
        while i < len(nums) - 1:
            if nums[i] == nums[i + 1]:
                nums[i] *= 2
                nums[i + 1] = 0
            i += 1
        
        for num in nums:
            if num != 0:
                array.append(num)
            else:
                zero_count += 1
        
        while zero_count > 0:
            array.append(0)
            zero_count -= 1
        
        return array
