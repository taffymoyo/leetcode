# 2586. Count the Number of Vowel Strings in Range
## What I learned
* Nothing new, just clean set lookup for vowel checking
## Approach
1. Iterate over the subarray from index left to right inclusive
2. Check if the first and last character of each word are vowels
3. Increment count if both conditions are met
## Complexity
Time: O(n) where n is right - left + 1  
Aux Space: O(1) — vowel set is fixed size
## Solution
```python
class Solution:
    def vowelStrings(self, words: List[str], left: int, right: int) -> int:

        vowels = {'a', 'e', 'i', 'o', 'u'}
        count = 0

        for i in range(left, right + 1):
            if words[i][0] in vowels and words[i][-1] in vowels:
                count += 1
        
        return count
```
