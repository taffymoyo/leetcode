# 3000. Maximum Area of Longest Diagonal Rectangle
## What I learned
* Collect all indices with the longest diagonal, then find max area among them
* sqrt not needed — comparing diagonal² is equivalent and avoids floating point
* list.clear() resets a list in place
## Approach
1. Track the longest diagonal seen and indices of rectangles with that diagonal
2. On new longest, clear the list and start fresh
3. On tie, append to list
4. Return max area among tied rectangles
## Complexity
Time: O(n)  
Aux Space: O(n) for lds list
## Solution
```python
class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:

        lds = []
        longest_diagonal = 0

        for i, rec in enumerate(dimensions):
            length, width = rec
            diag_length = sqrt(length ** 2 + width ** 2)

            if diag_length > longest_diagonal:
                lds.clear()
                lds.append(i)
                longest_diagonal = diag_length
            elif diag_length == longest_diagonal:
                lds.append(i)
        
        max_area = 0
        for i in lds:
            max_area = max(dimensions[i][0] * dimensions[i][1], max_area)
        return max_area
```
