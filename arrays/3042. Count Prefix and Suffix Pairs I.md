# 3042. Count Prefix and Suffix Pairs I
## What I learned
* For each pair (i, j) with i < j, check whether words[i] is both a prefix and a suffix of words[j] by slicing both ends
* The suffix slice words[j][len(words[j]) - window:] works, but words[j][-window:] is shorter. Both give the last window characters
* If words[i] is longer than words[j], both slices just return all of words[j], so the comparison fails naturally with no extra bounds check
* str.startswith() and str.endswith() do the same job and read more clearly
## Approach
1. For every pair (i, j) where i < j, take the length of words[i]
2. Compare words[j]'s first window characters and last window characters to words[i]
3. If both match, words[i] is a prefix and suffix of words[j], so increment count
## Complexity
Time: O(n² * m) where n is the number of words and m is the max word length
Aux Space: O(m) for the slices created on each comparison
## Solution
```python
class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:

        count = 0
        for i, word in enumerate(words):
            for j in range(i + 1, len(words)):
                window = len(word)
                if words[j][:window] == word and words[j][len(words[j]) - window:] == word:
                    count += 1
        return count
```
