# 2553. Separate the Digits in an Array

## What I learned
* That I'm capable of solving problems in under a minute

## Approach
1. Loop over each element in the array and convert it to a string (because int type is not iterable)
2. When adding digits back into the result list, make them integers again and return the result after all digits are considered.

## Complexity
Time: O(n) where n is the number of digits in all the numbers  
Aux Space: O(n) where n is the number of digits in all the numbers

## Solution
class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        
        result = []
        for num in nums:
            str_num = str(num)
            for digit in str_num:
                result.append(int(digit))
        
        return result
