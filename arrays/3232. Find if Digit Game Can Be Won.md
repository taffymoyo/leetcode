# 3232. Find if Digit Game Can Be Won

## What I learned
* A more advanced application of the ternary operator using two variables rather than one

## Approach
1. Find the max Alice can achieve with single digits and double digits only, separately, whichever is higher is Alice's number
2. Whatever the lower alternative is, is Bobs number, returns True if Alice can win the game

## Complexity
Time: O(n)
Aux Space: O(1)

## Solution
class Solution:
    def canAliceWin(self, nums: List[int]) -> bool:
        
        alice_count = 0
        bob_count = 0

        single_count = 0
        double_count = 0

        for num in nums:
            if num < 10:
                single_count += num
            else:
                double_count += num
    
        alice_count, bob_count = (single_count, double_count) if single_count > double_count else (double_count, single_count)

        return alice_count > bob_count
