# 2535. Difference Between Element Sum and Digit Sum of an Array
## What I learned
* Used floor division and modulus to extract digits without string conversion — more confident with this approach now
* num % 10 gets the last digit, num //= 10 strips it
## Approach
1. Accumulate element sum directly
2. For each number extract its digits using repeated % 10 and // 10, accumulate digit sum
3. Return absolute difference
## Complexity
Time: O(n * d) where d is the number of digits per number  
Aux Space: O(1)
## Solution
```python
class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        
        element, digit = 0, 0

        for num in nums:
            element += num

            while num >= 10:
                last_digit = num % 10
                digit += last_digit
                num //= 10

            digit += num

        return abs(element - digit)
```
