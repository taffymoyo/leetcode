# 3978. Unique Middle Element
## What I learned
* Nothing new, simple index and linear scan
## Approach
1. Find the middle element using len(nums) // 2
2. Scan the array — if the middle value appears at any index other than the middle, return False
3. Otherwise return True
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def isMiddleElementUnique(self, nums: list[int]) -> bool:

        middle = nums[len(nums) // 2]
        
        for i, num in enumerate(nums):
            if num == middle and i != len(nums) // 2:
                return False
        return True
```
