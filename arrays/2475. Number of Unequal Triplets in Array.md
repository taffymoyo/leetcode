# 2475. Number of Unequal Triplets in Array
## What I learned
* Grouping by frequency and counting combinations across groups is O(n) vs O(n³) brute force
* For each group, multiply elements to its left × elements in group × elements to its right
## Approach
### Brute Force O(n³)
1. Use three nested loops with increasing indices i < j < k
2. Check all three pairwise inequality conditions
3. Increment count if all conditions are met
### Optimal O(n)
1. Count frequency of each unique value using Counter
2. For each unique value with frequency j, multiply:
   - l = count of elements seen so far (left of current group)
   - j = size of current group (middle)
   - r = count of elements not yet seen (right of current group)
3. This counts all valid triplets where each element comes from a different group — guaranteed to be pairwise distinct
## Complexity
Brute Force — Time: O(n³), Aux Space: O(1)
Optimal — Time: O(n), Aux Space: O(n) for the Counter
## Solution
```python
class Solution:
    def unequalTriplets(self, nums: List[int]) -> int:

        count = 0
        for i in range(len(nums)):
             for j in range(i + 1, len(nums)):
                 for k in range(j + 1, len(nums)):
                    if nums[i] != nums[j] and nums[i] != nums[k] and nums[j] != nums[k]:
                        count += 1
        
        return count
```
## Optimised Solution
```python
class Solution:
    def unequalTriplets(self, nums: List[int]) -> int:
        c = Counter(nums)
        ans = 0
        l, r = 0, len(nums)
        for i, j in c.items():
            r -= j
            ans += l * j * r
            l += j
        return ans
```
