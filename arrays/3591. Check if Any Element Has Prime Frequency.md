# 3591. Check if Any Element Has Prime Frequency
## What I learned
* any() returns True if at least one element in an iterable is truthy — cleaner than an explicit loop with return True
* Prime check: only need to check divisors up to √n since factors come in pairs
* n**0.5 is square root — ** is the power operator not multiplication
## Approach
1. Count frequencies of each element using Counter
2. For each frequency check if it's prime using a helper function
3. Return True if any frequency is prime
## Complexity
Time: O(n + m√m) where n is len(nums) and m is the max frequency
Aux Space: O(n) for the Counter
## Solution
```python
class Solution:
    def checkPrimeFrequency(self, nums: List[int]) -> bool:

        def is_prime(n):
            if n < 2:
                return False
            for i in range(2, int(n**0.5) + 1):
                if n % i == 0:
                    return False
            return True

        counts = Counter(nums)
        return any(is_prime(freq) for freq in counts.values())
```
