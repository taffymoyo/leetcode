# 2215. Find the Difference of Two Arrays

## What I learned
* nothing, just became more confident with set difference

## Approach
1. Get the set difference for each array to find which elements are distinct to each array
2. Return the respective distinct elements

## Complexity
Time: O(n + m) where n and m are the length of the two arrays respectively
Aux Space: O(n + m) where n and m are the length of the two arrays respectively

## Solution
class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:

        arr1 = list(set(nums1) - set(nums2))
        arr2 = list(set(nums2) - set(nums1))
        return [arr1, arr2]
