# 2363. Merge Similar Items
## What I learned
* defaultdict(int) could simplify this — no need to check if key exists, just += directly
* Sorting a list of lists sorts by first element by default
## Approach
1. Use a dict to accumulate weights by value across both item lists
2. Convert dict back to list of [value, weight] pairs
3. Sort by value
## Complexity
Time: O((n + m) log(n + m)) dominated by sort  
Aux Space: O(n + m) for the dict
## Solution
```python
class Solution:
    def mergeSimilarItems(self, items1: list[list[int]], items2: list[list[int]]) -> list[list[int]]:

        seen_vals = {}
        result = []

        for val, weight in items1:
            if val not in seen_vals:
                seen_vals[val] = weight
            else:
                seen_vals[val] += weight
        
        for val, weight in items2:
            if val not in seen_vals:
                seen_vals[val] = weight
            else:
                seen_vals[val] += weight
        
        for key, val in seen_vals.items():
            result.append([key, val])
        result.sort()
        
        return result
```
