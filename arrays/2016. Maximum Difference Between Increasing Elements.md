# 2016. Maximum Difference Between Increasing Elements
## What I learned
* Tracking a running minimum removes the need for a nested loop
* "Vibes programming" sometimes works but understanding why it works matters for edge cases
## Approach
### Brute Force O(n²)
1. For every pair (i, j) where i < j, compute nums[j] - nums[i]
2. Track the maximum difference where nums[j] > nums[i]
### Optimised O(n)
1. Track a running minimum as you scan left to right
2. For each element, if it's greater than the running minimum, compute the difference and update max
3. Otherwise update the running minimum
## Complexity
Brute Force — Time: O(n²), Aux Space: O(1)  
Optimised — Time: O(n), Aux Space: O(1)
## Brute Force Solution
```python
class Solution:
    def maximumDifference(self, nums: List[int]) -> int:

        max_difference = -1
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                difference = nums[j] - nums[i]
                if difference > max_difference and difference != 0:
                    max_difference = difference
        
        return max_difference
```
## Optimised Solution
```python
class Solution:
    def maximumDifference(self, nums: List[int]) -> int:

        min_val = nums[0]
        max_diff = -1

        for j in range(1, len(nums)):
            if nums[j] > min_val:
                max_diff = max(max_diff, nums[j] - min_val)
            else:
                min_val = nums[j]
        
        return max_diff
```
