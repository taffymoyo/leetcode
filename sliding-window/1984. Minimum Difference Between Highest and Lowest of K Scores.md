# 1984. Minimum Difference Between Highest and Lowest of K Scores
## What I learned
* 10^5 is XOR in Python not exponentiation — use 10**5 (I know this but i spent 30 mins overlooking such a stupid mistake)
* Sliding window on unsorted array doesn't work — sorting first ensures adjacent elements are the closest possible, making consecutive windows always optimal
* Key insight: minimum spread for any k-group must come from consecutive elements in sorted order — non-consecutive elements can only be further apart
* Combination of sorting + sliding window — sorting eliminates irrelevant combinations
* If k == 1, difference is always 0
## Approach
1. Sort the array — optimal k-groups are always consecutive in sorted order
2. Slide a window of size k, tracking min (left) and max (right) of each window
3. Return the minimum difference seen
## Complexity
Time: O(n log n) dominated by sort  
Aux Space: O(n) for sorted copy
## Solution
```python
class Solution:
    def minimumDifference(self, nums: list[int], k: int) -> int:

        min_difference = 10**5 + 1 if k > 1 else 0
        i, sorted_nums = 0, sorted(nums)    
        minimum, maximum = sorted_nums[i], sorted_nums[k - 1]

        while k <= len(sorted_nums):
            if (maximum - minimum) < min_difference:
                min_difference = maximum - minimum
            
            i, k = i + 1, k + 1
            if k <= len(sorted_nums):
                minimum, maximum = sorted_nums[i], sorted_nums[k - 1]
        
        return min_difference
```
