# 187. Repeated DNA Sequences
## What I learned
* Sliding window of fixed size 10 — classic pattern for fixed-length substring problems
* Two sets: seen to track all substrings, repeated to avoid adding duplicates to result
## Approach
1. Slide a window of size 10 across the string
2. If substring not in seen, add to seen
3. If already in seen and not in repeated, add to result and repeated
## Complexity
Time: O(n * 10) = O(n) — each slice is O(10)  
Aux Space: O(n) for the two sets
## Solution
```python
class Solution:
    def findRepeatedDnaSequences(self, s: str) -> list[str]:

        seen = set()
        repeated = set()
        result = []

        for i in range(10, len(s) + 1):
            if s[i-10:i] not in seen:
                seen.add(s[i-10:i])
            else:
                if s[i-10:i] not in repeated:
                    result.append(s[i-10:i])
                    repeated.add(s[i-10:i])

        return result
```
