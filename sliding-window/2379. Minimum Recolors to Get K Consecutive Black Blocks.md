# 2379. Minimum Recolors to Get K Consecutive Black Blocks
## What I learned
* Sliding window of fixed size k — count W's in each window, track the minimum
* str.count(substring) counts occurrences of a character/substring in a string
* Could be more optimised by keeping track of the W count rather than recomputing it each time
## Approach
1. Slide a window of size k across the string
2. Count white blocks in each window — that's the number of recolors needed
3. Return the minimum count across all windows
## Complexity
Time: O(n * k) — each window.count() is O(k), done n-k+1 times
Aux Space: O(k) for the window slice
## Solution
```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:

        i, j = 0, k
        count = k

        while j <= len(blocks):
            window = blocks[i:j]
            w_count = window.count("W")
            count = min(count, w_count)

            i, j = i + 1, j + 1
        
        return count
```
