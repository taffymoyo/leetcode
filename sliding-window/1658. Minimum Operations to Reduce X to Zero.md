# 1658. Minimum Operations to Reduce X to Zero
## What I learned
* Think in reverse — instead of minimising elements removed from ends, maximise the middle subarray
* target = sum(nums) - x, find the longest subarray summing to target
* Window length formula is r - l + 1 not r - l - 1
* If target < 0, impossible — return -1 early
## Approach
1. Compute target = sum(nums) - x
2. Sliding window to find maximum length subarray summing to target
3. Expand right pointer, shrink left when sum exceeds target
4. Answer is len(nums) - max_length
## Complexity
Time: O(n)  
Aux Space: O(1)
## Solution
```python
class Solution:
    def minOperations(self, nums: list[int], x: int) -> int:

        l, current_sum = 0, 0
        num_sum = sum(nums)
        target = num_sum - x
        maximum = -1

        for r in range(len(nums)):
            current_sum += nums[r]
        
            while current_sum > target and l <= r:
                current_sum -= nums[l]
                l += 1
            
            if current_sum == target and r - l + 1 > maximum:
                maximum = r - l + 1
                
        return len(nums) - maximum if maximum != -1 else -1
```
