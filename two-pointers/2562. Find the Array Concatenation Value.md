# 2562. Find the Array Concatenation Value
## What I learned
* Two pointers from both ends pair up the first and last elements, and the loop ends when they meet or cross
* When i == j there is one element left, so only add that element once instead of concatenating it with itself
* Concatenating two numbers can be done with strings (int(str(a) + str(b))) or with math (a * 10**len(str(b)) + b)
* A conditional expression (x if cond else y) can handle the single-element case inline, so no separate temp list is needed
## Approach
1. Start one pointer at each end of nums
2. While i <= j, add int(str(nums[i]) + str(nums[j])) to the total, or just nums[i] if i == j
3. Move the pointers inward
## Complexity
Time: O(n * d) where d is the max number of digits in an element
Aux Space: O(d) for the temporary strings
## Solution
```python
class Solution:
    def findTheArrayConcVal(self, nums: List[int]) -> int:
        
        total = 0
        i, j = 0, len(nums) - 1
        
        while i <= j:
            str_i, str_j = str(nums[i]), str(nums[j])
            total += int(str_i + str_j) if i != j else int(str_i)
            i, j = i + 1, j - 1  
        return total
```
