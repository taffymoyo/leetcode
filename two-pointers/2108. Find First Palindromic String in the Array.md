# 2108. Find First Palindromic String in the Array
## What I learned
* Two pointer palindrome check: l and r converge inward, if they cross (l >= r) without mismatch it's a palindrome
* Works for both even and odd length strings — odd length the pointers meet at the middle character
## Approach
1. For each word use two pointers from both ends
2. If any characters don't match, break — not a palindrome
3. If pointers cross without breaking, it's a palindrome — return it
4. Return "" if none found
## Complexity
Time: O(n * m) where n is number of words and m is average word length  
Aux Space: O(1)
## Solution
```python
class Solution:
    def firstPalindrome(self, words: list[str]) -> str:

        for word in words:
            l, r = 0, len(word) - 1

            while l < r:
                if word[l] == word[r]:
                    l, r = l + 1, r - 1 
                else:
                    break
            if l >= r:
                return word
                
        return ""
```
